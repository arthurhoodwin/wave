# Wave 1.1.2.2

## Скачивание

- После временного отказа аудиосервера Wave может один раз получить свежую ссылку и повторить загрузку. Повторы ограничены; ограничения доступа и длительное ожидание сервера не запускают бесконечную загрузку.
- Исправлена проверка длительности обычных AAC и MP3: теперь учитываются аудиокадры, а не только первоначальная оценка браузера. Это помогает с файлами переменного битрейта.
- Для проверки используется свежая длительность выбранной записи VK. Обрезанное аудио и несовпадение песни по-прежнему отклоняются.
- В сообщении серверной ошибки теперь виден HTTP-код; ограничение доступа отделено от временного сбоя.

После обновления нажмите «Повторить» или «Продолжить» у неудавшейся загрузки. Если сам источник по-прежнему недоступен, может понадобиться другая запись песни.

Небольшой `.waveupdate` предназначен для **1.1.2.1**. Для первой установки или перехода с другой версии используйте `Wave-Setup-1.1.2.2.exe`. Настройки, вход и готовые скачанные песни сохраняются.
