# Wave 1.1.6.1

Исправили панель действий в «Мне нравится»: поиск и сортировка теперь находятся рядом с кнопкой «Слушать», как в остальных плейлистах. Поле поиска раскрывается справа от значка лупы.

Для **1.1.6** доступен небольшой `.waveupdate`. Для остальных версий используйте `.exe`. Вход, настройки и скачанные песни сохраняются.
