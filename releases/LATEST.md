# Wave 1.1.0-alpha.5

Доработка развёрнутого плеера и скорости лайка перед Beta. Предварительный выпуск; стабильный Latest остаётся **1.0.9.9.1**.

## Плеер и текст

- Плеер использует ширину окна вместо ограничения 1440 px. Обложка, сведения и текст распределены между двумя колонками; нижний транспорт и шкала занимают ширину карточки. В стенде на 1920 px ширина шкалы/футера — 1856 px, поля — по 32 px.
- Переключатель «Плеер / Текст» удалён. Единственный основной вид содержит сведения о песне и текст; кнопка полного экрана сохранена.
- Источник и сведения об авторстве находятся **после последней строки** внутри прокручиваемого текста. Сверху остаются только поиск текста, ошибка или отсутствие текста.
- Подсветка строки плавно меняет цвет и фон, сопровождение прокручивает текст плавно. Ручная прокрутка останавливает сопровождение, кнопка «К текущей строке» возвращает его. При prefers-reduced-motion сдвиги и переходы отключаются, прокрутка мгновенная.
- Нижняя боковая кнопка мыши («Назад») закрывает развёрнутый плеер, включая собственный полный экран. Песня продолжает играть, история страниц не сдвигается. Дублирующий сигнал той же физической кнопки не вызывает второй переход.

## Панель и списки

- Мини-плеер и настройки находятся рядом с аккаунтом у правого края верхней панели.
- Для «Скачанного» исходная сортировка — **«Дата скачивания · новые сверху»**; обратная — старые сверху. Данные сортируются по дате завершения независимо от порядка в индексе. В обычных VK-списках название «Порядок VK» сохранено.
- Между длительностью, лайком и скачиванием выделено больше места. Центры заголовков и кнопок остаются совмещёнными.

## Лайк: короткий запрос записи

Исправление Alpha 4 давало быстрый визуальный отклик, но ещё ожидало полное чтение библиотеки для подтверждения. В Alpha 5 обычное добавление в «Мне нравится» выполняет **один audio.add** и завершает действие по корректному числовому ответу VK. Удаление использует точную известную копию текущего аккаунта и audio.delete; при неизвестной принадлежности сохранён осторожный путь проверки.

Локальный список обновляется по подтверждению записи. Полная сверка запускается отдельно с задержкой 250 мс и объединяется при последовательных действиях. Старый фоновый результат не должен перезаписать более новое подтверждённое изменение. Ошибки записи не повторяются автоматически; некорректный ответ считается неопределённым, сердце возвращается к прежнему состоянию с ошибкой. Смена аккаунта проверяется перед записью.

Это сокращает необходимую сетевую работу; время ответа самого VK зависит от соединения. Реальное время на всех CDN/аккаунтах не измерялось.

## Проверено

**233 автоматические проверки**, включая одиночный запрос quick-like без чтения библиотеки, удаление своей копии вместо исходной, отказ при смене аккаунта, неопределённый ответ без повторной записи, обновление локальной коллекции и сортировку скачанного.

В изолированном Electron с искусственной песней и метками проверены: единый вид без переключателя, источник последним элементом текста, промежуточное положение плавной прокрутки и её завершение, мгновенный reduced-motion режим, боковая кнопка с сохранением страницы/паузы, правый край панели, подписи сортировки и расстояние 50 px между центрами лайка и скачивания. Ошибка выравнивания колонок — 0 px.

Плеер проверен axe на 1920×1080, 1424×914, 1100×720, 550×360 и 320×780: выбранные WCAG A/AA правила без нарушений, горизонтального переполнения нет. Ручная проверка экранного диктора и разных физических мышей/компьютеров не проводилась.

## Установка

**Wave-Setup-1.1.0-alpha.5.exe** или подписанный пакет **Wave-1.1.0-alpha.5.waveupdate** из Alpha 1–4. Переход со стабильной версии — через EXE. Профиль, история, закрепления и локальные файлы сохраняются. Windows FileVersion — 1.1.0.5.

Ограничения Alpha сохранены: HLS пока не скачивается, продолжение загрузки после паузы начинается заново, источник рекомендаций VK не подключён. Пакеты подписаны Ed25519; Authenticode-сертификата пока нет.
