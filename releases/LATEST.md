# Wave 1.2.6

- **Мини-плеер поверх окон.** Перетащите компактную панель туда, где она удобна. По умолчанию Ctrl+Shift+F9 раскрывает управление песней даже из другого приложения. Экран, положение и сочетание клавиш можно настроить.
- **Память перемешивания.** Wave запоминает пройденный порядок списка между запусками. В настройках воспроизведения можно начать новый круг.
- **Отдельный аудиовыход.** Выберите устройство для Wave в настройках воспроизведения. Если оно станет недоступно, звук вернётся на системное устройство.
- **Проба караоке.** Wave может ослабить голос по центру локальной стереозаписи WAV. Результат можно прослушать и сохранить отдельным файлом.

Обновление доступно в настройках Wave.
