# Wave 1.0.9

## Обновления внутри Wave

В настройках появились **«Проверить новые версии»**, **«Скачать обновление»**, прогресс и отмена загрузки. Проверка запускается пользователем; фоновой проверки и автоматической установки нет.

- Источник — стабильный Latest релиз `arthurhoodwin/wave` на GitHub. Выбирается пакет `.waveupdate` для версии релиза. Произвольные адреса от интерфейса не принимаются; HTTPS и перенаправления ограничены GitHub и его CDN.
- Размер, обрыв загрузки, подпись Ed25519 и SHA-512 проверяются до предложения установки. Версия внутри подписи обязана совпадать с версией публикации. Подмена, чужой хост и отменённый пакет не становятся установщиком.
- **«Установить»** и **«Откатить»** сохраняют явное подтверждение. Перед запуском установщика контрольная сумма проверяется повторно. Загрузка из файла также сохранена.
- После некорректного завершения той же версии появляется **«Восстановление»** с переходом к настройкам и предложением сохранённой версии. Это предложение, а не автоматический откат; при отсутствии резервного установщика есть инструкция ручного восстановления.

Новый загрузчик проверен на настоящем опубликованном пакете 1.0.8: 119 162 395 байт загрузки, затем успешная проверка подписи и установщика 119 162 033 байта в изолированном каталоге. Установщик в этой проверке не запускался. Авторизация VK во внешние запросы не передаётся.

## Crossfade и предзагрузка

**Настройки → Переходы между песнями**: перекрытие от 0 до 12 секунд и отдельный выключатель предзагрузки следующей песни. Перекрытие по умолчанию выключено; предзагрузка включена и использует дополнительный трафик.

- Настройка действует при **автоматическом** переходе внутри текущего контекста. Ручной выбор, предыдущая/следующая кнопка и перемотка отменяют подготовленный переход.
- Вторая песня подготавливается отдельно, без остановки текущей. Наложение использует независимые gain-огибающие Web Audio перед общим эквалайзером. Громкость продолжает работать на обоих источниках.
- Пауза сразу убирает затухающий хвост; после перехода остаётся один активный источник. Смена выбора и неудачная подготовка освобождают ресурсы. Ошибка подготовки не делает песню навсегда недоступной.
- Повтор одной песни и таймер «до конца трека» исключают автоматическое перекрытие. Список продолжается по прежним правилам; обязательной очереди справа нет.
- Если подготовка не успела, Wave использует обычный запуск. При 0 секундах подготовленная песня может использоваться на окончании текущей, но это **не обещание gapless**: непрерывность декодированных сэмплов для MP3/AAC/HLS ещё не измерена.

## Настройки и восстановление

Миграция старых настроек сохраняет параметры интерфейса, мини-плеера и текста; новые параметры получают безопасные значения. Схема настроек теперь помечена `settingsVersion: 1` для дальнейших миграций. Неизвестные значения и неправильные типы не принимаются. Инструкция восстановления, пути к резервным установщикам и границы отката обновлены в [UPDATES.md](https://github.com/arthurhoodwin/wave/blob/main/docs/UPDATES.md).

## Проверки и ограничения

- **177 автоматических проверок**, включая настоящую криптографическую проверку тестовых пакетов, подмену, чужой адрес и redirect, обрыв/отмену, несовпадение подписанной версии, признак аварии, миграции, предзагрузку и отмену перехода.
- В настоящем Electron на собственных синтетических WAV и HLS проверены два одновременно работающих источника, завершение огибающих, пауза, громкость и очистка до нуля соединений. Ошибок media/prepare-error в прогоне нет.
- Полный интерфейс на синтетическом аудио автоматически переключил песню с перекрытием; ручной выбор убрал хвост, таймер остановки исключил предзагрузку.
- Проверены настройки с клавиатуры, состояния проверки/скачивания/готовности и окна 1424×914, 1100×720, 550×360, 320×780. В проверенных состояниях нет горизонтального переполнения и замечаний axe.
- На этом компьютере обычная установка 1.0.8 → 1.0.9 и штатный откат на сохранённую 1.0.8 завершились с кодом 0; затем выполнено повторное обновление. Это проверка версии и файлов, без инспекции авторизованного VK-окна.
- Реальная публичная загрузка и подпись проверены на GitHub. Crossfade на текущем авторизованном VK-аккаунте отдельно не проверен: способ проверки с отладочным портом был отклонён автоматической проверкой безопасности. Ограничение не обходилось. Сеть VK/CDN и разные аудиоформаты могут влиять на готовность следующей песни.
- Проверки на чистой Windows, независимых компьютерах, аппаратных аудиоустройствах и ручной экранный диктор остаются дальнейшей работой. Authenticode-сертификата нет. Подпись `.waveupdate` не заменяет подпись Windows.

## Установка

Установщик — **Wave-Setup-1.0.9.exe**, подписанный пакет — **Wave-1.0.9.waveupdate**. Из 1.0.7/1.0.8 пакет можно выбрать в настройках; проверка GitHub из интерфейса доступна начиная с этой версии. Из исторических 1.0.61/1.0.62 используйте установщик из-за старого сравнения версий.

Вход и коллекция сохраняются. SHA256SUMS.txt служит для сравнения файлов. Исходники этой версии опубликованы под GPL-3.0-only. Домашняя, постоянная история, скачивание музыки и офлайн-библиотека остаются в плане 1.1.
