# Wave 1.1.0-beta.5

## Маленькие обновления

- Новый подписанный формат переносит изменённые блоки, новые файлы и удаления. Неизменённый Electron повторно не скачивается.
- Точная исходная версия и SHA-512 файлов проверяются до подготовки и после закрытия приложения. Неподходящий пакет не применяется.
- Прежние файлы сохраняются для отката. При обычной ошибке записи помощник возвращает уже заменённые файлы.

**Beta 5 устанавливается через Wave-Setup-1.1.0-beta.5.exe один раз.** Beta 4 ещё не понимает новый формат. Поэтому в этом переходном релизе нет `.waveupdate`; маленькие пакеты будут использоваться со следующего выпуска. Полный EXE остаётся для первой установки, пропущенных версий и восстановления.

## Порядок и уборка

Завершена публикация забытых Alpha 2, Alpha 3 и Alpha 6: список снова идёт от новых бет к старым альфам. Старые теги и файлы сохранены, стабильный Latest — 1.0.9.9.1.

Из локального dist удалены старые установщики и пакеты: освобождено 5 125 729 873 байта. Добавлена команда `npm run artifacts:clean`, сохраняющая текущую версию. Эти файлы и раньше не входили в Git.

## Проверки

289 тестов. В отдельном каталоге Windows проверены изменение/добавление/удаление файлов, точный обратный откат, повреждение пакета и подготовленного файла, неверная основа, небезопасные пути, junction и возврат прежних файлов при блокировке одного из назначений.

На настоящих упакованных сборках сравниваются все 77 файлов после применения и после отката. Работающее окно и профиль пользователя не меняются; установку владелец выполняет вручную. Размер и границы проверки — [VALIDATION.md](https://github.com/arthurhoodwin/wave/blob/main/docs/VALIDATION.md).

Пакет проверяет изменения файлов, но не гарантирует атомарность при выключении питания во время замены. Восстановление в таком случае — полным установщиком. Windows FileVersion: 1.1.0.105.
