# Wave 1.1.5

Скачивание стало быстрее и удобнее.

- Wave по умолчанию скачивает **до трёх песен одновременно**. В настройках можно выбрать 1, 2 или 3 загрузки. Пауза и отмена по-прежнему доступны для отдельных песен и всей очереди.
- Добавлена выключенная по умолчанию настройка **«Автоматически скачивать песню, добавленную в „Мне нравится“»**. Она действует на новые лайки, поставленные через Wave. Прежняя коллекция автоматически не скачивается, снятие лайка не удаляет локальную копию.
- В «Скачанном» появилась сортировка **«Как в „Мне нравится“»**. Песни вне коллекции идут после неё, новые сверху. После первого полного чтения коллекции порядок доступен и без сети.
- В новые **MP3** записываются название, исполнитель, доступное название альбома и обложка — для сторонних плееров. Аудио не перекодируется. Ранее скачанные файлы не изменяются.

При ограничениях аудиосервера Wave временно снижает число одновременных загрузок. Прерывание одной задачи не останавливает остальные; квота места остаётся общей.

Для **1.1.4** доступен небольшой `.waveupdate`. Для остальных версий используйте `.exe`. Вход, настройки и скачанные песни сохраняются.
