# Wave 1.1.3.1

Исправили страницы исполнителей после обновления 1.1.3.

- Если альбомы и синглы нельзя полноценно разделить — одна категория пуста или тип релизов не указан — вместо двух вкладок показывается одна: **«Релизы»**. В ней собраны все эти записи без повторов.
- Полученные треки артиста больше не исчезают, если Wave не распознал блок популярности VK. В таком случае они показываются во вкладке **«Треки»**; название «Популярные треки» используется, когда этот порядок подтверждён источником.
- Если доступных треков действительно нет, скрываются пустая таблица, фильтр и неработающая кнопка «Слушать».

Небольшой файл `.waveupdate` предназначен для **1.1.3**. Для остальных версий используйте `.exe`. Вход, настройки и скачанные песни сохраняются.
