# Wave 1.2.2

Тексты скачанных песен теперь остаются доступны без сети.

- Откройте текст скачанной песни онлайн один раз: Wave сохранит его вместе с временными метками и источником рядом с аудио. Если текст уже найден до скачивания, он сохранится после загрузки песни.
- Сохранённый текст не исчезает через неделю и не вытесняется из обычного кэша. Синхронная подсветка и переход по строке работают без сети.
- Рядом с размером текста появилась кнопка обновления. Если получить новый текст не удалось, прежний остаётся доступен.
- Если текст ещё не сохранён, без сети показывается понятное сообщение. Бесконечных попыток загрузки нет.
- При удалении локальной песни удаляется и связанный текст. Его размер учитывается в лимите хранилища.

Аудио становится готовым независимо от сохранения текста. Wave не обходит всю коллекцию ради загрузки текстов: для старых скачанных песен достаточно открыть текст при наличии сети.

Обновление доступно в настройках Wave. Вход, настройки и скачанная музыка сохраняются.
