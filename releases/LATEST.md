# Wave 1.1.6

Обновили интерфейс и исправили статус автоматически скачанных песен.

- «Мне нравится» теперь учитывает связь исходной песни с её копией в VK: прогресс и галочка скачивания показываются у соответствующей записи. Связь сохраняется после перезапуска; повторное скачивание готовой копии не требуется. Для старых записей Wave пробует безопасно подтвердить соответствие при полном чтении коллекции.
- Закрепления перенесены в верхнюю группу медиатеки. Закреплённый плейлист или альбом отмечен залитой иконкой; главная остаётся рекомендательной.
- Поиск внутри плейлиста и сортировка находятся рядом с действиями в шапке. Поле поиска раскрывается справа от иконки.
- Выпадающие списки сортировки и настроек оформлены в стиле меню медиатеки, с клавиатурным управлением и едиными состояниями.
- Короткие подтверждения действий появляются снизу и быстро исчезают, не сдвигая страницу. Ошибки, требующие решения, остаются видимыми.
- Убраны копирование ссылки из плеера и дублирующий поиск внутри глобальной выдачи.
- Добавлены сдержанные градиенты близких оттенков и согласованы состояния новых элементов.

После обновления откройте «Мне нравится» при подключении к VK, чтобы обновить данные коллекции. Если для старой записи соответствие нельзя подтвердить, Wave не ставит галочку наугад.

Для **1.1.5** доступен небольшой `.waveupdate`. Для остальных версий используйте `.exe`. Вход, настройки и скачанные песни сохраняются.
