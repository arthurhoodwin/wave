# Wave 1.2.0.1

Исправлено качество обложек в развёрнутом плеере.

- Маленькая обложка трека больше не перекрывает крупную обложку из данных альбома: Wave выбирает лучший доступный размер из обоих источников.
- При наличии сети старая обложка скачанной песни больше не заменяет свежую версию из VK при открытии личных разделов. Без сети остаётся доступна сохранённая обложка.
- Крупная версия изображения не подменяется уменьшенной копией из кэша списка.

Обновление доступно в настройках Wave. Музыка, вход и настройки сохраняются. Качество ограничено исходниками, которые предоставляет VK; если сама исходная картинка маленькая, восстановить её детали невозможно.
