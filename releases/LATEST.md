# Wave 1.1.0-beta.2

## Интерфейс

- Убраны поиск плейлистов в боковой медиатеке и выбор их порядка. Они перенесены в далёкие планы вне 1.1. Переключатель обычного/компактного вида остаётся; ранее сохранённая сортировка больше не применяется.
- Закреплённые списки остаются первыми. Обновление структуры медиатеки использует линейную проверку элементов вместо повторного поиска по массиву.

## Очередь и локальные файлы

- При смене аккаунта загрузки ставятся на паузу. При возвращении в тот же аккаунт можно продолжить очередь; записи и файлы не смешиваются между аккаунтами.
- Параметры продолжения прямого файла сохраняются до записи данных. При аварийном завершении подходящий частичный файл можно продолжить по Range с проверкой источника и сильного ETag.
- Повторная загрузка после ошибки использует прежнюю задачу и её подходящие частичные данные. Ошибочную задачу можно отменить из интерфейса и освободить место.
- Лимит места учитывает также незавершённые файлы. При превышении вместимости каталога пакет отклоняется целиком, без наполовину добавленной очереди.
- Если журнал очереди не удалось сохранить, новые задачи не начинают скачиваться. Продолжение без сети показывает понятное сообщение; смена папки требует завершения или отмены ошибочных задач.
- Непрошедший проверку готовый файл удаляется вместе со служебными файлами. Дополнительно проверяется соответствие длительности песни с допуском на округление.
- Нечитаемый индекс истории/скачанного или неизвестная версия его формата больше не заменяются пустой медиатекой. Файл остаётся без изменений, приложение сообщает об ошибке.
- Запоздавший ответ личной медиатеки отклоняется после смены аккаунта.

## Проверено

261 автоматическая проверка. Среди новых сценариев — настоящее принудительное завершение отдельного процесса и продолжение по Range, смена аккаунта, повтор после обрыва, лимит каталога, ошибка сохранения журнала, отмена частичного файла и защита нечитаемого индекса.

На изолированном демонстрационном профиле: список из 10 000 песен сохраняет 30 строк в DOM; переходы Главная → плейлист → медиатека не пересоздают её строки. Проверены 1366×768, масштаб Electron 200% и размеры 320–1920 px: переполнений и нарушений автоматической проверки доступности после завершения анимаций не найдено. Это синтетические проверки, не замер скорости на всех компьютерах.

## Ограничения

Реальные подборки и лайки разных аккаунтов VK, настоящие варианты HLS, длительные прогоны и независимые Windows-компьютеры ещё требуют проверки. Поддержка HLS не расширена: завершённые packed AAC/MP3, AAC в TS, fMP4 и обычный AES-128 identity. HLS после паузы собирается заново; восстановленная очередь на паузе. Метаданные остаются в JSON рядом с аудио, встроенные теги пока не записываются. Старые локальные копии не переобрабатываются автоматически.

## Установка

**Wave-Setup-1.1.0-beta.2.exe** или подписанный **Wave-1.1.0-beta.2.waveupdate** из предыдущей Alpha/Beta. Со стабильной версии используйте EXE. Профиль, история, закрепления и локальные файлы сохраняются. Windows FileVersion — 1.1.0.102. Выпуск предварительный; стабильный Latest остаётся 1.0.9.9.1.
