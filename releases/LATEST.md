# Wave 1.0.3

Первый публичный выпуск Wave — независимого Windows-клиента VK Музыки.

## Установка

Скачайте **Wave-Setup-1.0.3.exe**, установите и войдите через официальное окно VK внутри Wave. Нужны Windows x64 и интернет.

**Wave-1.0.3.waveupdate** — подписанный пакет для обновления уже установленной Wave. Выберите его в настройках приложения. Для первой установки используйте EXE.

## Возможности

- Коллекция VK, плейлисты, поиск, страницы исполнителей и альбомов.
- Запуск песни одним кликом, скрытый контекст из текущего списка, повтор и перемешивание.
- Сердечко, управление плейлистами, проверка результата изменений в VK.
- Развёрнутое окно песни с текстом, когда его предоставляет VK.
- Мини-плеер, мультимедийные клавиши, трей, таймер сна и восстановление позиции.
- Тёмная зелёная палитра и локальный Inter Variable.

## Исправление 1.0.3

Устранена ошибка «Недопустимый сервер аудио VK» для потоков `okcdn.ru`. Все девять треков контрольного альбома успешно запущены. 95 автоматических проверок прошли на машине разработки.

## Ограничения

Внутренний веб-протокол VK может изменяться. Встречались успешные пустые ответы поиска; исследование включено в роадмап. Текст зависит от записи, синхронной подсветки нет. Офлайн-аудио не поддерживается.

Установщик пока без Authenticode-подписи. Ed25519-подпись `.waveupdate` проверяется самой Wave и не заменяет подпись Windows. SHA256SUMS.txt позволяет сравнить загруженные файлы, но сам по себе не является цифровой подписью.
