# Wave 1.1.4

Вернули подборки на главную и исправили названия альбомов в плеере.

- Wave распознаёт актуальные разделы VK: «Собрано алгоритмами», «Выбор редакции», новые альбомы, жанровые подборки и рекомендации песен. Набор разделов зависит от аккаунта.
- Алгоритмические плейлисты теперь открываются в Wave. Они доступны для прослушивания, но не для редактирования как собственные списки.
- При временном сбое уже загруженные подборки сохраняются. Кнопка «Повторить» делает новое чтение; обновление данных не пересоздаёт одинаковые карточки и не сбивает фокус.
- Исправлен случай «Альбом · unnamed», когда настоящее название уже доступно в VK. Имя уточняется при открытии плеера и согласуется со страницей альбома, контекстом воспроизведения и историей.

Жанровые плейлисты доступны из «Обзора». Персональные кнопки жанров и настроений, запускающие VK Микс, относятся к будущему обновлению1.2.

Для **1.1.3.2** доступен небольшой `.waveupdate`. Для остальных версий используйте `.exe`. Вход, настройки и скачанные песни сохраняются.
