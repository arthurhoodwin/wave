# Wave 1.1.9

Обновления с пропуском версий — без повторного скачивания полного установщика.

- Новый загрузчик сам выбирает совместимый небольшой пакет или наиболее выгодную цепочку. Подготовка проходит заранее, затем Wave перезапускается один раз.
- Для стабильных версий1.1.0–1.1.8.3 подготовлены отдельные небольшие переходы сразу на1.1.9. В старой версии скачайте файл «from-ваша-версия» и откройте его в настройках через «Выбрать файл обновления». После перехода новый автоматический выбор уже встроен в приложение.
- Если прямого патча нет, предусмотрен запасной пакет компонентов приложения с использованием совместимых файлов Electron на ПК. Полный установщик остаётся для первой установки и аварийного восстановления.
- Перед установкой проверяются подписи, совместимость основы и конечные файлы. Загрузку можно отменить; доступен откат к исходной версии, в том числе после составного перехода.
- Улучшено восстановление прерванной замены файлов. Вход, настройки и скачанные песни сохраняются.

Для1.1.8.3 обычный `Wave-1.1.9.waveupdate`; для более старых выпусков — файл с вашей версией после `from-`. Пакет `runtime` предназначен для нового загрузчика1.1.9 и следующих версий.
