# Wave 1.1.0-alpha.6

Исправление проверки лайка и новая документация. Предварительный выпуск; стабильный Latest остаётся **1.0.9.9.1**.

## «Мне нравится»

В Alpha 5 быстрый путь принимал только положительное целое подтверждение audio.add. Другой JSON-тип сразу превращался в ошибку «VK не подтвердил запись» и откатывал сердце — даже без проверки, выполнилась ли запись.

Теперь принимаются безопасные числовые идентификаторы, числовые строки и явные поля audio_id/id с проверкой владельца. Противоречивый ответ или чужой владелец не создают выдуманную локальную копию.

Если ответ не удалось распознать, Wave **один раз читает актуальную коллекцию**, не повторяя audio.add. Найденная точная запись или однозначная копия подтверждает лайк. Если сеть недоступна, аккаунт сменился или результат неоднозначен, появляется сообщение о необходимости проверить коллекцию. Нераспознанный тип сам по себе больше не приводит к мгновенному отказу. Результат, уже проверенный чтением, не запускает ещё одну фоновую полную проверку.

Исправлен также сквозной путь этого подтверждения: отсутствие таймера фоновой проверки больше не вызывает ошибку обработчика коллекции.

Фактическое тело ответа VK из пользовательского случая не было получено. REA-проверка сохранённых публичных скриптов не установила контракт этого RPC; границы исследования и стратегия восстановления описаны в [VK-OWNERSHIP.md](../docs/VK-OWNERSHIP.md).

## README для пользователя

README переписан целиком: скачивание обычного выпуска и Alpha, установка, вход, основные функции, кнопки, ограничения и сообщение об ошибке. Убраны техническая схема, команды сборки, история всех версий и подробности подписи.

Для разработчиков и авторов форков создан **DEVELOPMENT.md**: запуск, структура, изоляция собственного профиля, ключи и адреса обновлений, проверка и сборка. Ссылки между документами проверены.

## Проверено

**240 автоматических проверок**, включая число/строку/объект, незнакомый успешный ответ, чтение после ответа без повторной записи, неоднозначность, потерю сети, смену аккаунта и сквозное применение результата через VkProvider.

Настоящее тело ответа инцидента и проверка записи на разных аккаунтах VK остаются вне этой проверки. Синтетические случаи покрывают как быстрое подтверждение, так и восстановление через чтение.

## Установка

**Wave-Setup-1.1.0-alpha.6.exe** или подписанный пакет **Wave-1.1.0-alpha.6.waveupdate** из предыдущей Alpha. Со стабильной версии переходите через EXE. Профиль, история, закрепления и локальные файлы сохраняются. Windows FileVersion — 1.1.0.6.

Остальные ограничения Alpha сохранены: HLS пока не скачивается, продолжение загрузки начинается заново, рекомендации VK не подключены. Пакеты обновлений подписаны Ed25519; установщик пока без Authenticode-сертификата.
