# Wave 1.0.5

## Новый поиск VK

- Четыре раздела: **Песни, Исполнители, Альбомы, Плейлисты**. Используются реальные сущности каталога VK, а не подбор карточек из названий песен.
- Основная выдача переведена на проверенный `catalog.getAudioSearch` с параметром `query`. Продолжение — через `catalog.getBlockItems` и серверные курсоры.
- Новая отправка поиска прерывает старый запрос; поздний ответ не подменяет результаты. Ошибка, настоящий пустой ответ и подсказки вместо результатов обрабатываются отдельно. При ошибке доступна кнопка «Повторить поиск», которая запрашивает данные заново.
- Карточки исполнителей и альбомов открывают соответствующие страницы. Новые страницы раскрываются при прокрутке, без кнопки «Загрузить ещё» и без пересоздания неизменных карточек.
- При возврате к недавно открытому поиску сохраняются раздел, загруженные страницы и прокрутка. Кэш содержит до восьми контекстов; контекст звучащего поиска сохраняется при вытеснении остальных.
- Следующие песни из поиска подгружаются даже после ухода на другую страницу. Открытая медиатека при этом не подменяется результатами поиска.

## История запросов

Недавние запросы появляются при фокусе в поисковой строке. Их можно выбрать мышью или клавиатурой и очистить. Сохраняются последние 20 запросов без повторов; история хранится локально через safeStorage, изолирована по аккаунту и очищается при выходе. Это история поисковых запросов, не история прослушивания.

## Каталог исполнителей

- При нескольких точных совпадениях имени Wave предлагает выбрать исполнителя через соответствующий раздел поиска, а не автоматически смешивает профили.
- Совместные релизы сохраняются у основных авторов. Если в блоке релизов возвращён альбом с другими основными авторами, он относится к участию.

## Проверки

- **116 автоматических проверок** локально. Новые случаи: типизированные результаты, параметр query, курсоры и повтор страниц, неполные ответы, отмена запросов, кэш возврата, независимое продолжение звучащего поиска, история и её шифрование/очистка, одинаковые имена и совместные альбомы.
- На текущем аккаунте проверены четыре раздела и их продолжения, открытие исполнителя/альбома и запуск песни из поиска. У Kai Angel и 9mice в основных релизах присутствуют Heavy Metal 2 и HEAVY METAL; участие показано отдельно.
- Реальный сценарий: запуск последней из 20 загруженных песен → переход в медиатеку → следующий трек. Контекст расширился до 70, следующая песня играет, медиатека осталась открытой.
- Проверены возврат к разделу и прокрутке, сохранение DOM-карточек при добавлении страницы, история/очистка, переключение вкладок стрелками и выбор недавнего запроса Enter.
- 1424×914, 1100×720, 550×360, 320×780: без горизонтального переполнения и замечаний axe в проверенных состояниях. Пустое и ошибочное состояния дополнительно проверены управляемыми ответами интерфейса.

## Ограничения

Старое успешное пустое `audio.search` сейчас не воспроизвелось; его точная серверная причина не установлена. Для основной выдачи Wave больше от него не зависит. VK может возвращать неточные совпадения даже для искусственных запросов; результаты поиска не являются строгим совпадением строки. Полнота всей дискографии и одинаковая выдача на других аккаунтах не гарантируются. Структура заголовков каталога проверена для русского и предусмотрена для английского, остальные локализации отдельно не проверены.

Проверки выполнены на этом компьютере; ручной экранный диктор и другие Windows-машины не проверялись. Эквалайзер и остальные функции 1.0.4 сохраняются. Скачивание песен остаётся в плане 1.1.

## Установка

Первая установка — **Wave-Setup-1.0.5.exe**. Обновление установленной Wave — **Wave-1.0.5.waveupdate** через настройки. Вход и коллекция сохраняются. Нужны Windows x64 и интернет.

Установщик без Authenticode; пакет Wave имеет существующую подпись Ed25519. SHA256SUMS.txt служит для сравнения файлов и не заменяет подпись. Исходники соответствующей версии под GPL-3.0-only доступны в Source code этого релиза.
