# Wave 1.1.3.2

Страница исполнителя больше не показывает промежуточный интерфейс при загрузке.

- Вкладки, списки, фильтр и кнопка «Слушать» появляются после получения данных — сразу с окончательными названиями и составом разделов.
- Пока информация загружается, остаются шапка артиста и сообщение загрузки. Это работает и при повторном обновлении страницы.
- Выбранная вкладка и прокрутка сохраняются.

Для **1.1.3.1** доступен небольшой `.waveupdate`. Для остальных версий используйте `.exe`. Вход, настройки и скачанные песни сохраняются.
