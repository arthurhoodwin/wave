# Wave 1.0.9.5

## Настройки и плеер

- Исправлен огромный синий флажок «Подготавливать следующую песню»: общий стиль текстовых полей больше не применяется к флажкам и ползункам.
- Флажки настроек имеют единый размер 18×18 px, зелёный акцент, подпись рядом и видимый фокус клавиатуры. Подпись целиком переключает настройку.
- Ползунок перекрытия песен занимает отдельную строку, значение остаётся возле подписи. Прокрутка настроек не передаётся странице позади окна.
- Обновления позиции больше не сбивают основной ползунок, пока пользователь его перетаскивает. Отпускание ползунка после смены песни не перематывает новую запись.

## Перемотка за пределы буфера

- Аудиопрокси сохраняет Content-Length, Accept-Ranges и Content-Range: Chromium может запросить нужные байты прямого аудиофайла без ожидания его полной загрузки. Для HTTP-декодированного содержимого исходный Content-Length не переносится.
- При переходе в незагруженный участок HLS загрузка начинается с целевой позиции. Перемотка ограничена длительностью песни, а не текущим буфером.
- Подтверждение приходит после фактического перехода и готовности аудио. Пауза сохраняется; смена песни отменяет ожидание. Через 8 секунд появляется отдельная ошибка перемотки с предложением повторить действие, без автоматического возврата к другой песне.

## Проверено

184 автоматические проверки. Изолированный Electron: искусственный WAV 80 с, выдаваемый по 16 КиБ каждые 50 мс через настоящий аудиопрокси; переход на 60 с вызвал Range с байта 5 275 648, затем перемотка на паузе на 25 с — с байта 2 195 456. Искусственный HLS VOD запросил сегмент 15 у позиции 60 с вместо продолжения загрузки начала. Ошибок аудио не было; после сброса не осталось аудиографов. Это функциональная проверка, не замер скорости серверов VK и не гарантия поддержки любого кодека/CDN.

Настройки проверены axe и при ширине 1424, 1100, 550 и 320 CSS px: нарушений выбранных WCAG A/AA правил и горизонтального переполнения не найдено. Проверены управление ползунком с клавиатуры и его сохранение. Ручная проверка экранного диктора и других компьютеров не проводилась.

## Установка и номер версии

Используйте **Wave-Setup-1.0.9.5.exe**. Авторизация, коллекция и настройки сохраняются. Старые версии до 1.0.9 включительно распознают только трёхчастные версии обновлений: для перехода на этот выпуск нужен установщик. Начиная с 1.0.9.5 загрузчик и подписанные пакеты поддерживают четыре части и корректный порядок 1.0.9 < 1.0.9.5 < 1.0.10 < 1.1.0.

В npm техническая версия — `1.0.9-5`, версия продукта, тег, установщик, диагностический отчёт и подписанный пакет — **1.0.9.5**. Версия Windows-файла — 1.0.9.5. Подпись пакетов Ed25519 сохранена; Authenticode-сертификата у установщика пока нет.
