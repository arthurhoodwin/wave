# Wave 1.1.2.3

Исправление скачивания песен.

- Песни с ошибочной длительностью в каталоге VK теперь сохраняются, если файл получен целиком и его длительность подтверждается проверками аудио. В «Скачанном» отображается фактическая длительность записи.
- При ошибке аудиосервера HTTP 504 Wave пробует дополнительный способ запроса файла. Если сервер продолжает отвечать ошибкой, загрузку можно повторить позже.
- Проверка целостности файлов сохранена: недокачанная запись не добавляется в скачанные песни.

После обновления нажмите «Повторить» у неудачных загрузок.

Для обновления с **1.1.2.2** подойдёт небольшой файл `.waveupdate`. Для остальных версий используйте полный установщик `.exe`. Вход, настройки и скачанные песни сохраняются.
