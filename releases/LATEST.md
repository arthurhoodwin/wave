# Wave 1.1.3

Обновили страницы исполнителей.

- Широкие изображения используются в шапке, а аватар показывается отдельно. Обложка песни больше не выдаётся за фотографию исполнителя.
- Музыка разделена на вкладки «Популярные треки», «Альбомы», «Синглы» и «Участие в релизах». Доступность разделов зависит от данных VK; релизы без указанного типа отмечаются отдельно.
- В релизах показывается год, когда он доступен. Полученные релизы можно упорядочить по названию или году.
- Возврат на страницу сохраняет выбранную вкладку и положение прокрутки. Длинные списки карточек не перегружают страницу.
- Сбой загрузки одного раздела не скрывает остальные, а быстрые переходы больше не позволяют старому ответу заменить новую страницу.

С **1.1.2.3** можно обновиться небольшим файлом `.waveupdate`. Для других версий используйте `.exe`. Вход, настройки и скачанные песни сохраняются.
