# Wave 1.2.4

Эквалайзер теперь раскрывается над панелью воспроизведения. В нём шесть полос в одном ряду, а настройки из прошлой версии автоматически переносятся.

- При включении эквалайзера Wave компенсирует изменение общего уровня и сглаживает самые громкие пики. Особенно заметна разница с прежней версией, когда усилена одна полоса.
- Сохраняйте собственные пресеты, переименовывайте их и переносите между установками Wave через JSON. Импорт и экспорт находятся внизу панели эквалайзера.
- В редакторе своего плейлиста можно выбрать обложку, настроить кадр и посмотреть результат перед применением. Такая обложка действует только в Wave. Обложку VK можно вернуть в том же редакторе.
