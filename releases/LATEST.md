# Wave 1.1.8.1

Выровняли расстояния между кнопками в шапке плейлиста: закрепление, удаление, сортировка и поиск теперь расположены с одинаковыми промежутками. Пустой счётчик больше не создаёт лишний отступ.

Для **1.1.8** доступен небольшой `.waveupdate`. Для остальных версий используйте `.exe`. Вход, настройки и скачанные песни сохраняются.
