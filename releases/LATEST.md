# Wave 1.1.8.3

Плейлисты других пользователей VK теперь тоже можно добавлять в свою медиатеку и убирать из неё — кнопкой в шапке и через меню списка слева.

Удаление из своей медиатеки не удаляет оригинальный плейлист другого пользователя. Обычные плейлисты сохраняют свой тип; удаление собственного плейлиста остаётся отдельным действием с подтверждением.

Для **1.1.8.2** доступен небольшой `.waveupdate`. Для остальных версий используйте `.exe`. Вход, настройки и скачанные песни сохраняются.
