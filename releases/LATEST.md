# Wave 1.0.4

## Эквалайзер

Шесть полос **60 / 170 / 350 / 1000 / 3500 / 10000 Гц**, диапазон ±12 дБ, пресеты «Ровный», «Бас», «Вокал», «Мягкий», сброс и выключение обработки. Значения применяются во время движения ползунка и сохраняются между запусками.

Открыть: кнопка эквалайзера возле громкости или **Настройки → Эквалайзер**. По умолчанию обработка выключена. При усилении полос рассчитывается запас громкости по частотной характеристике с дополнительными 3 дБ; звук может стать тише. Это эквалайзер, не нормализация громкости. При невозможности вычислить характеристику используется более консервативный запас.

## Воспроизведение

- «Следующий/Предыдущий», мини-плеер и системные команды доступны во время загрузки песни.
- При новом выборе прерывается запрос ссылки предыдущей записи. Отмена не переводит весь аккаунт в состояние «Нет сети».
- Пауза во время получения ссылки запрещает последующий автоматический запуск.
- Запоздалые ответы прежних выборов не меняют выбранную песню и не показывают её ошибку поверх новой.
- При ошибке уже начавшегося потока выполняется одна попытка восстановления с сохранением позиции и намерения паузы; бесконечных повторов нет.
- Разделены категории неподдерживаемого сервера, временной сетевой ошибки, истёкшей ссылки и ограничения доступа. Временный сбой не помечает песню навсегда недоступной.

## Диагностика

**Настройки → Сохранить диагностику** создаёт JSON в выбранном месте. В нём версия, платформа, счётчики запросов и категории последних ошибок. Нет названий песен, аккаунта, cookies, токенов, адресов потоков и путей профиля. Отчёт никуда не отправляется автоматически. Отмены выбора не засоряют журнал.

## Проверено

- **102 автоматические проверки** локально: отмена 20 запросов, пауза во время загрузки, восстановление, защита от устаревших ответов, категории ошибок, сохранение приватности диагностики и эквалайзер.
- Реальный VK: восемь MP3-записей воспроизводятся с эквалайзером и растущей позицией; серия 20 быстрых выборов закончилась на последней песне, одно действующее соединение Web Audio.
- Реальный HLS/Hls.js: локально созданный AAC/fMP4-сигнал, рост позиции, включённый EQ и обход, без ошибок. Это тест формата, не утверждение о проверке всех HLS-серверов VK.
- OfflineAudioContext: обход, нейтральный пресет, бас и все полосы +12 дБ на контрольном сигнале без нечисловых значений и превышения пика 1. Это ограниченная проверка, не гарантия отсутствия перегруза для любой записи/любого транзиента.
- Экспорт через настоящий IPC проверен в изолированном пустом профиле; лишние поля отклоняются.
- Эквалайзер проверен на 1424×914, 1100×720, 550×360, 320×780: нет горизонтального переполнения и замечаний axe в проверенных состояниях. ArrowUp меняет полосу, Escape закрывает окно и возвращает фокус, в том числе при открытии из настроек.

## Установка и ограничения

Для новой установки — **Wave-Setup-1.0.4.exe**. Для установленной Wave — **Wave-1.0.4.waveupdate**, выбрать в настройках. Нужны Windows x64, интернет и аккаунт VK. Сеанс и коллекция сохраняются.

Используется внутренний протокол VK; его изменения могут потребовать фиксов. Проблема успешных пустых ответов поиска остаётся в плане 1.0.5. Реальное многочасовое отключение сети, все аудиоустройства и другие компьютеры в этой версии не проверены. Gapless/crossfade не входят в 1.0.4.

Установщик без Authenticode. Пакет `.waveupdate` подписан Ed25519 и проверяется Wave; SHA256SUMS.txt помогает сравнить загрузки, но не заменяет цифровую подпись. Исходники под GPL-3.0-only доступны в Source code этого релиза.
