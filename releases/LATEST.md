# Wave 1.2.7.1

Мини-плеер автоматически скрывается, когда окно Wave получает фокус. При сворачивании Wave включённый мини-плеер появляется в компактном виде.

Раскрытие и сворачивание по горячей клавише стали плавнее. При быстром повторном нажатии анимация меняет направление с текущего кадра.

Обновление доступно в настройках Wave.
