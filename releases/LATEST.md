# Wave 1.0.62

## Компактный мини-плеер

- Высота окна подстраивается под содержимое: пустая полоса снизу убрана. При появлении таймера сна или сообщения окно расширяется, а после их исчезновения снова уменьшается.
- Добавлены перемешивание, повтор списка/песни и сердечко. Активные состояния синхронизируются с основным плеером.
- Лайк использует существующую операцию VK. Для удаления из «Мне нравится» основное окно открывает подтверждение; скрытого диалога не остаётся.
- Кнопка скрытия перенесена в верхний ряд возле кнопки открытия Wave.
- Исправлены записи версий четырёх зависимостей в lock-файле: возвращены фактические закреплённые версии 1.0.6; сами зависимости не обновлялись.

## Проверки

129 автоматических проверок проходят. Новые случаи: состояния мини-плеера, доступность лайка без сети, передача команд и безопасный размер окна. В реальном Electron на демонстрационных данных проверены шесть кнопок, повтор одной песни, лайк, перемешивание, ширины 390 и 324 px и расширение при таймере сна. Замечаний axe в проверенном состоянии нет.

Высота содержимого без статуса — 175 px, с таймером — 195 px. Это логические пиксели; рамка и масштаб Windows могут менять внешний размер.

## Установка

Установщик — **Wave-Setup-1.0.62.exe**. Подписанный пакет через настройки — **Wave-1.0.62.waveupdate**. Вход и коллекция сохраняются. Установщик без Authenticode; пакет обновления подписан Ed25519.
