# Wave 1.1.0-beta.4

## Лайк нижней панели

- Для повторного добавления собственной удалённой копии используется восстановление `audio.restore` вместо копирования удалённого источника через `audio.add`.
- Подтверждение допускает до двух свежих чтений с короткой паузой; запись при этом не повторяется. Учитываются округление длительности и незначительные различия пробелов.
- После удаления одной копии другая одноимённая запись не считается доказательством неудачи. При нескольких совпадениях учитывается известное состояние до операции.
- Истёкшая удалённая копия получает понятное предложение найти песню в поиске. Смена сеанса во время подтверждения отклоняет старый результат.

Это исправление проверено на воспроизводимых ответах подменённого API. Владелец выбрал ручную проверку своего VK; настоящий результат на его аккаунте пока не подтверждён.

## Без сети

- В развёрнутом плеере работают кнопки переключения сохранённых песен.
- «Следующий» и «Предыдущий» пропускают несохранённые записи. Повтор офлайн не ждёт удалённое продолжение списка.
- Скачанная копия остаётся доступна при недоступной записи VK; при отсутствии серверной длительности используется длительность локальной копии.
- Изменение локальной доступности сразу обновляет строки и управление.

## Что проверено

- **279 автоматических тестов**, без пропусков.
- Искусственный файл 65 минут: обрыв, продолжение после перезапуска, проверка длительности.
- Воспроизведение этого файла без исходного сервера: пауза, продолжение, перемотка на 60-ю минуту, 0 внешних запросов.
- Chromium-декодирование тестовых HLS AAC, AES-128 TS и fMP4.
- Искусственный профиль, записанный кодом стабильной 1.0.9.9.1: настройки и позиция читаются, используется Windows safeStorage.
- Настоящие подписанные пакеты: проверка Beta 4 и выбор проверенного отката со стабильной версии и Beta 3. Исполнение установщика в этой проверке заменено журналированием.

Подробные условия и непроверенные пункты — [матрица проверок](https://github.com/arthurhoodwin/wave/blob/main/docs/VALIDATION.md). Живой VK, другие аккаунты и фактическую установку/откат владелец проверяет вручную; отдельной Windows-среды нет. Часовые прогоны и профилирование памяти не входили в этот выпуск.

## Установка

**Wave-Setup-1.1.0-beta.4.exe** или подписанный **Wave-1.1.0-beta.4.waveupdate** из предыдущей Alpha/Beta. Со стабильной версии используйте EXE. Windows FileVersion — 1.1.0.104. Выпуск предварительный, стабильный Latest остаётся 1.0.9.9.1. Текущее окно Wave не перезапускалось автоматически.
