# Wave 1.2.6.3

- Мини-плеер подхватывает цвет обложки текущей песни и затемняет фон до чёрного.
- Клик за пределами раскрытого мини-плеера сворачивает его. Островок по-прежнему скрывается при фокусе Wave, возвращается компактным при сворачивании и плавно реагирует на повторное нажатие горячей клавиши.
- Этот выпуск возвращает аудиотракт 1.2.6 без выравнивания громкости песен.

Из 1.2.6.2 можно обновиться в настройках Wave. Если установлен выпуск с более высоким номером, воспользуйтесь полным установщиком.
