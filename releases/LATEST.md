# Wave 1.1.0-beta.1

## Плеер и текст

- Исполнитель выровнен с названием и обложкой.
- Подсветка синхронного текста использует текущую позицию самого аудиоплеера. Цвет меняется сразу по метке, короткая анимация не задерживает выбор строки.
- Нажатие на строку с временной меткой перематывает песню к ней; доступны Tab и Enter/пробел. Текст без меток остаётся обычным текстом.
- В развёрнутом и полноэкранном плеере статус находится слева, управление по центру, громкость справа; на узком окне блоки переносятся.

## Медиатека и Главная

- Поиск плейлистов по названию/исполнителю, сортировка и компактный вид. Настройки вида сохраняются отдельно для аккаунтов. Закреплённые списки идут первыми, отмечаются в боковой панели и остаются на Главной.
- Загрузка подборок VK в фоне: «Для вас», «Плейлисты дня», «Новые релизы». Показываются только фактически возвращённые подходящие списки; при недоступности источника есть соответствующее состояние. Выдача на реальном аккаунте ещё требует проверки.
- Сохранены исправления подтверждения лайков из Alpha 6: незнакомый ответ проверяется чтением, повторная запись не отправляется.

## Скачивание

- Совместимые завершённые HLS: AAC/MP3, AAC в MPEG-TS, fMP4 с инициализацией; обычный AES-128 identity поддерживается. Сохраняется фактический формат AAC/M4A/MP3. DRM/SAMPLE-AES, live, byte-range HLS и разрывы формата не поддерживаются.
- Прямые файлы продолжаются по Range только с совпадающим сильным ETag, адресом источника и корректным Content-Range. Если источник изменился или сервер не подтвердил продолжение, загрузка начинается заново.
- Очередь и подходящие частичные файлы сохраняются после перезапуска. Восстановленная очередь остаётся на паузе: нажмите «Продолжить». HLS после паузы собирается заново.
- Новые загрузки сохраняют автономную обложку и JSON с названием, исполнителем, альбомом и длительностью рядом с аудио. Встроенные ID3/MP4-теги пока не записываются; старые загрузки не переобрабатываются автоматически.
- Локальные обложки проверяются по размеру и SHA-256, доступны только текущему аккаунту; удаление копии удаляет также обложку и JSON. Лимит места учитывает эти файлы.

## Проверено и что остаётся

251 автоматическая проверка. Дополнительно: интерфейс на 320–1920 px и автоматическая проверка доступности; совпадение краёв обложки/исполнителя; центр управления; переход по строке; фильтр без пересоздания строк. Настоящий синтетический HLS собран в M4A и прочитан Chromium с корректной длительностью.

Нужны проверки разных аккаунтов VK, настоящих вариантов HLS, независимых Windows-компьютеров и длительной работы. Beta — предварительный выпуск. Покупка сертификата Authenticode исключена из плана; криптографическая проверка пакетов Wave сохранена.

## Установка

**Wave-Setup-1.1.0-beta.1.exe** или подписанный **Wave-1.1.0-beta.1.waveupdate** из Alpha. Со стабильной версии переходите через EXE. Вход, история, закрепления и скачанное сохраняются. Windows FileVersion — 1.1.0.101. Стабильный Latest остаётся 1.0.9.9.1.
