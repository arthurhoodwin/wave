# Участие в Wave

Перед крупной доработкой откройте issue с задачей и ожидаемым поведением. Ориентируйтесь на [роадмап](ROADMAP.md) и [дизайн-систему](DESIGN-SYSTEM.md): существующая палитра сохраняется, обычный клик сразу запускает песню, очередь не должна становиться обязательным шагом.

## Проверка изменений

1. Node.js 24, Windows x64: `npm ci`.
2. Запустите `npm test`.
3. Для интерфейса проверьте клавиатуру, фокус, длинные названия и reduced motion. Приложите скриншоты без личных данных.
4. Для VK-адаптера добавьте тесты с синтетическими ответами. Не коммитьте реальные токены, cookies, приватные ключи, аудио или подписанные адреса потоков.
5. В PR опишите изменение, способ проверки и ограничения. Сетевые записи не должны повторяться автоматически после неоднозначного результата.

Тесты не требуют аккаунта VK. Ручные проверки выполняйте только на своём разрешённом аккаунте; результат операции сверяйте с VK. Закрытый ключ официальных обновлений не нужен для обычной разработки.

Вклад принимается на условиях GPL-3.0-only. Сторонние ресурсы добавляйте только с совместимой лицензией и указанием происхождения.
