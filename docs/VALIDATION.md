# Проверки текущей Beta

Версия: **1.1.0-beta.6**. Дата: 24 октября 2026. Актуальное дополнение — дизайн и первый публичный файловый патч от Beta 5. Ниже также сохранены условия проверок Beta 4: VK, скачивание, обновление/откат и офлайн. Длительные прогоны воспроизведения и профилирование памяти не выполнялись.

## Дизайн Beta 6

Общая графитовая палитра theme.css для двух плееров, нейтральные подписи и статус скачивания, ограниченный мятный акцент. Компактные системные шапки, три нативных сворачиваемых раздела настроек, светлая текущая строка текста без зелёной заливки. Исправленный контраст меню плейлиста: #989f9c / #141617 = **6,72:1**, opacity 1.

- **290 тестов**, без пропусков. Один новый сценарий проверяет явный повтор подборок после кэшированного отказа, общий in-flight запрос и отказ без сети.
- Изолированный настоящий Electron с демонстрационными данными: Главная, коллекция, скачанное, текст с временными метками, загрузка/пустой текст/ошибка с повтором, offline. Axe во всех проверенных состояниях — без нарушений после исправлений.
- Настройки: все три группы отдельно и вместе, Enter/Space, отсутствие повторных id, существующие onclick/onchange сохранены, версия остаётся последним элементом.
- Размеры: 1440×950, 1100×720, 1920×1080, 320×800, реальный zoomFactor 2. На проверенных экранах не найдено горизонтального переполнения. 320 px — стресс-тест renderer; нативное окно имеет собственный minWidth.
- Reduced motion: opacity без transform. Forced colors: после исправления основной кнопки Axe не сообщает нарушения на коллекции и настройках.
- Отдельный скрытый мини-плеер: семь кнопок, лайк, режимы, таймер, громкость, длинные названия, сведения и масштаб до 200%; без переполнения/обрезанных кнопок и без нарушений Axe.
- Скриншоты в README обновлены на демонстрационные данные. Реальные аккаунты VK, полный скринридерный обход и независимый Windows-ПК не использовались и не подтверждены этим прогоном.

При первом запуске отдельного тестового Electron под ограниченным Windows-токеном среда отказала в доступе к runtime-каталогу и показала диалог ошибки. Остановлен именно тестовый процесс; проверка повторена через разрешённый запуск изолированного скрытого стенда и прошла. Установленный Wave и его профиль не запускались, не закрывались и не менялись. Это не считается воспроизведением сбоя установленного приложения.

Файловый патч Beta 5 → Beta 6: **407 562 байта**, меняются **2 из 77 файлов** (Wave.exe и app.asar; новые ресурсы добавлены внутри ASAR). Проверен настоящий ключ Wave и штатный менеджер/Windows-помощник. После применения и обратного отката размеры/SHA-512 всех 77 файлов отдельной распакованной копии совпали с целевой и исходной сборками соответственно. Все 101 упакованный исходный файл сверены с рабочим деревом. Перезапуск приложения в стенде отключён. Это проверка файлового протокола на текущем Windows, не независимая установка NSIS и не тест реального пользовательского профиля.

## Файловое обновление Beta 5

- На окончательных упакованных сборках Beta 4 → Beta 5 меняются **3 из 77 файлов**. Старый пакет Beta 4 весит **119 196 551 байт**, проверочный пакет нового формата — **227 255 байт**: уменьшение на **99,81%**, примерно в **525 раз**. Новых блоков до сжатия — 797 025 байт; неизменённые блоки берутся из основы.
- Использован настоящий ключ пакетов Wave; подпись проверена штатным UpdateManager. Применение выполнено настоящим PowerShell-помощником в отдельной копии распакованной сборки. Все 77 файлов побайтно сверены через размер/SHA-512 с окончательной Beta 5. Затем штатным обратным планом восстановлена Beta 4; все файлы снова совпали с основой.
- Это проверка файлов и помощника на текущем Windows, **не запуск установщика NSIS, не установка в рабочий каталог и не независимый Windows-ПК**. Перезапуск приложения в стенде отключён. Окно и профиль владельца не используются.
- **Beta 5 — переходная установка через EXE**. Её старый предшественник не понимает WAVEUPD2. Проверочный патч Beta 4 → Beta 5 не публикуется как применимое обновление; он использован для измерения и интеграционной проверки новым загрузчиком. Маленькие публичные пакеты предназначены для следующих версий на основе Beta 5.
- 10 новых тестов проверяют копирование блоков после вставки, новые/удалённые файлы, подпись/основу/контрольные суммы, пути/диапазоны/junction и реальное применение/откат. Помощник повторно проверяет подготовленный источник и откатывает уже заменённые файлы при блокировке позднего назначения.
- Всего **289 тестов**, без пропусков. При выключении питания в середине замены всего каталога атомарность не гарантируется; резервные файлы сохраняются, восстановление возможно полным EXE.

## Порядок и локальная уборка

24 октября завершена публикация исторических Alpha 2, Alpha 3 и Alpha 6, ранее оставленных черновиками. Проверен порядок GitHub API: Beta 4 → Beta 3 → Beta 2 → Beta 1 → Alpha 6 → … → Alpha 1. Теги/бинарники не пересозданы, стабильный Latest — 1.0.9.9.1. После публикации Beta 5 она становится первой предварительной версией.

Из dist удалены **5 125 729 873 байта** старых установщиков, пакетов и blockmap. 42 локальных EXE/пакета совпали с SHA-256 опубликованных assets; старый локальный EXE 1.0.3 отличался от публичного финального файла и удалён как устаревший результат сборки. Публичные assets сохранены. В Git ни один из этих бинарников не отслеживался. Сохранена текущая распакованная сборка для следующего патча и текущий установщик.

## Ручная проверка VK владельцем

1. Откройте Главную логотипом. Проверьте доступные подборки и переход из карточки к настоящему списку.
2. На тестовой песне снимите лайк нижней кнопкой и сразу верните. Проверьте сердце в плеере и строке, затем обновите «Мне нравится» и перезапустите приложение.
3. Добавьте из нижней панели другую песню, которой ещё нет в коллекции. Проверьте результат после обновления списка.
4. Если удалённую собственную копию уже нельзя восстановить, приложение предлагает найти песню в поиске; оно не отправляет новую запись наугад.

Повторить на других аккаунтах и другом Windows-ПК, когда они доступны. До этого не отмечать соответствующие пункты роадмапа выполненными.

## Примечание к исправлению лайка

Путь собственной удалённой копии проверен по коду и синтетическому сценарию. Назначение `audio.restore` описано в [документации VK.NET](https://vknet.github.io/vk/audio/restore/); это описание старой версии API, не доказательство ответа текущего VK. Поэтому исправление не объявляется натурно подтверждённым до ручного прогона владельцем.
