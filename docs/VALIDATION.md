# Проверки Wave

Версия: **1.1.5 Stable**. Дата: 26 октября 2026. Текущие результаты и границы проверки. Длительные прогоны и профилирование памяти не выполнялись.

## 1.1.5 · Загрузка и метаданные

369 Node-тестов прошли: три активных transfer одновременно, уменьшение настройки без обрыва работающих, общая квота/резервы и последовательное сохранение индекса, конкурентная постановка без дублей, пауза и восстановление,429/cooldown. Настройки3/off по умолчанию мигрируют и сохраняются по аккаунту. Проверены confirmed new like callback/массовый like, выключенная настройка, смена аккаунта, ошибка очереди без отмены лайка. Read-only reconcile не инициирует скачивание. Полный liked-order сохраняет verified source aliases; offline-сортировка оставляет записи вне коллекции после неё.

ID3 writer проверен на кириллице/APIC, удалении предыдущего ID3, побайтном совпадении аудиокадров до/после, сохранении длительности и отказе квоты без изменения оригинала. В отдельном Electron Chromium принял MP3 с новыми тегами:2,6122448979591835с, совпадает с100 MPEG-кадрами. Discovery UI проверяет выбор2 загрузок, opt-in toggle и сортировку по liked rank; прежние home/album, axe,1100/650/320 и zoom200% также проходят. Аудио не перекодируется. PNG/JPEG обложки встраиваются напрямую; WebP конвертируется в JPEG через Electron nativeImage. Встроенная картинка ограничена2МиБ, при ошибке картинки сохраняются текстовые теги и целое аудио.

Реальные лайки и массовые скачивания VK для проверки1.1.5 не выполнялись, рабочим окном не управляли. Оценка фактической скорости зависит от сервера и сети; не обещается трёхкратное ускорение. Старые копии не переписываются; неподтверждённый placeholder-альбом не записывается как достоверный TALB. Декодирование/длительность/контрольная сумма считаются по окончательному tagged-файлу. Поведение runtime воспроизведения при нагрузке трёх реальных CDN-потоков отдельно не измерялось; API-запросы фоновые и сохраняют приоритет слота playback.

Итоговые369 Node-тестов и три Electron-гейта прошли. Все119 исходников совпали с ASAR; FileVersion1.1.5.300. Подписанный пакет от точной1.1.4: 266812байт. Применение и откат на отдельной копии дали совпадение всех77 файлов; отчёт work/qa115-real-patch.json.

## 1.1.4 · Главная и имя альбома

Владелец явно разрешил чтение главной/одного альбома, затем отдельно разрешил временное обычное закрытие Wave для диагностических запросов через его адаптер с возвратом приложения. Native Computer Use снова вернул `coordinate input geometry is unavailable`; повторный keyboard input не изменил фокус, дальнейший ввод не выполнялся. Диагностика использовала штатный VkHttpClient и существующий session partition после обычного выхода Wave, без одновременного доступа двух процессов к профилю, без debugger, копирования/decryption cookie-файлов или печати авторизационных значений. Каждая законченная проверка возвращала установленный Wave. Не выполнялись команды добавления/удаления в коллекции, запуска музыки или управления загрузками. Временное закрытие и возврат Wave выполнялись с отдельного согласия владельца.

На реальном VK подтверждены две причины: текущие подписи/типы не совпадали с тремя прежними regex-группами; все8 generated-списков имеют отрицательные ID и отбрасывались общим keyOf. Проверено отдельно: getPlaylistById возвращает ту же generated identity, audio.get читает записи с этим playlist_id. Жанры/настроения персональной главной имеют action.type=play_vk_mix; это не готовые плейлисты.

Повторная проверка исправленного адаптера:12 разделов, state=ready, partial=false. Восстановлены8 алгоритмических списков; один прочитан целиком,100/100 записей с available=true, editable=false. Выбор редакции, новые альбомы, жанровые плейлисты и трековые рекомендации получены из реального ответа. В примере madam до исправления частичный title=unnamed, полный title=damage при той же identity; после исправления albumForTrack вернул damage с confirmed=true. Эти проверки не запускали воспроизведение. Отчёты work/catalog114-audit.json, catalog114-details.json и qa114-real-source.json остаются локально. В Git включён только проверенный обезличенный пример tests/fixtures/vk-home-catalog.json: ID, имена песен/списков, длительности и изображения заменены.

353 Node-теста. Новые регрессии: наблюдённая структура каталога, signed generated playlist identity без signed audio ID, неполный ответ, shared lookup альбома и защита полных имён, текущий/cached occurrence, сохранение истории между запусками, изоляция аккаунтов, fresh retry, поздний старый ответ, частичная ошибка и сохранение секций.

Изолированный Electron UI-гейт:4 синтетических раздела, неизменившиеся group/card/focus сохранены после обновления, generated-список открывается со скрытой неподтверждённой ссылкой, placeholder нейтрален до ответа и заменяется damage в current/list/loop. Из200 controls-обновлений не возникает нового lookup; альбомная страница обновляет имя обратно в плеер; ответ после reset не меняет новый трек. Axe после окончания переходов без нарушений;1100/650/320px и zoom200% без переполнения. Отчёт work/discovery-ui-report.json. Runtime payload настоящего VK проверен адаптером, клики нового UI и настоящее аудио на рабочем аккаунте не проверялись.

Пройдены отдельные Electron-гейты ASAR-обновления, артистов и discovery. Все117 упакованных исходников побайтно совпали с рабочим деревом; Windows FileVersion1.1.4.300. Подписанный пакет от точной1.1.3.2 —343246байт. Применение и откат на изолированной копии дали совпадение всех77 файлов; отчёт work/qa114-real-patch.json.
