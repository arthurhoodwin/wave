# Сборка и публикация обновления Wave

Клиент проверяет пакеты Ed25519 встроенным `build/update-public.pem`. Секретный ключ в исходники, установщик и каталог релизов не включён. Для следующих релизов нужен тот же ключ; его следует хранить резервно в защищённом месте. Закрытый ключ хранится отдельно от репозитория и не публикуется.

1. Поднимите версию в package.json/package-lock.json и заголовке UI. Запустите `npm test`.
2. `npm run dist` создаёт `dist/Wave-Setup-VERSION.exe`. Сборщик electron-builder 26.15.3, NSIS, Windows x64. Authenticode-сертификат пока не настроен.
3. Упакуйте установщик:

```powershell
node scripts/package-update.cjs dist/Wave-Setup-VERSION.exe dist/Wave-VERSION.waveupdate VERSION $env:WAVE_SIGNING_KEY
```

`WAVE_SIGNING_KEY` — путь к приватному PEM-файлу, не содержимое ключа. Скрипт проверяет соответствие публичному ключу, считает размер/SHA-512, подписывает манифест и добавляет неизменённый установщик. Не выдавайте один бинарник за другую версию. Файл назначения должен быть новым.

Пакет имеет magic `WAVEUPD1\n`, uint32 LE длины JSON envelope, envelope `{payload,signature}`, затем байты EXE. Подпись проверяется над точными UTF-8 байтами payload. Payload содержит product `app.wave.vk`, arch `x64`, version, bytes, sha512. Архивы не распаковываются, пути из пакета не исполняются.

Пользователь выбирает файл в настройках Wave, подтверждает установку. Установщик запускается после завершения приложения; перед запуском SHA-512 проверяется повторно. Помощник лежит вне ASAR (`app.asar.unpacked/build/windows`), использует UTF-8 JSON и .NET SHA-512. История установщиков защищена safeStorage. Откат доступен на сохранённую меньшую версию, а обычный импорт понижения версии отклоняется.

В `updates-v1/last-install.json` профиля сохраняются только стадия, числовой код и время, без музыкальных данных. Код 5 — контрольная сумма, 7 — ошибка помощника. Результат ошибки отображается в настройках при следующем запуске. Старый установщик можно запустить вручную, если приложение вообще не открывается. Автоматического отката по аварии нет.

Публичный сервер обновлений не настроен. Файлы можно передавать напрямую. Подключение сервера потребует отдельной настройки адреса публикации; подписывать следует все распространяемые обновления. Ротация ключа требует переходной версии, доверяющей новому ключу.

NSIS-настройки сверены с [документацией electron-builder](https://www.electron.build/v26/docs/nsis/). Подпись Ed25519 пакетов Wave — собственный формат и не является подписью Authenticode Windows.
