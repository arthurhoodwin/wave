# Сборка и публикация обновления Wave

Клиент проверяет пакеты Ed25519 встроенным `build/update-public.pem`. Секретный ключ в исходники, установщик и каталог релизов не включён. Для следующих релизов нужен тот же ключ; его следует хранить резервно в защищённом месте. Закрытый ключ хранится отдельно от репозитория и не публикуется.

1. Поднимите версию в package.json/package-lock.json и заголовке UI. Запустите `npm test`.
2. `npm run dist` создаёт `dist/Wave-Setup-VERSION.exe`. Сборщик electron-builder 26.15.3, NSIS, Windows x64. Authenticode-сертификат пока не настроен.
3. Упакуйте установщик:

```powershell
node scripts/package-update.cjs dist/Wave-Setup-VERSION.exe dist/Wave-VERSION.waveupdate VERSION $env:WAVE_SIGNING_KEY
```

`WAVE_SIGNING_KEY` — путь к приватному PEM-файлу, не содержимое ключа. Скрипт проверяет соответствие публичному ключу, считает размер/SHA-512, подписывает манифест и добавляет неизменённый установщик. Не выдавайте один бинарник за другую версию. Файл назначения должен быть новым.

Пакет имеет magic `WAVEUPD1\n`, uint32 LE длины JSON envelope, envelope `{payload,signature}`, затем байты EXE. Подпись проверяется над точными UTF-8 байтами payload. Payload содержит product `app.wave.vk`, arch `x64`, version, bytes, sha512. Архивы не распаковываются, пути из пакета не исполняются.

Пользователь выбирает файл в настройках Wave, подтверждает установку. Установщик запускается после завершения приложения; перед запуском SHA-512 проверяется повторно. Помощник лежит вне ASAR (`app.asar.unpacked/build/windows`), использует UTF-8 JSON и .NET SHA-512. История установщиков защищена safeStorage. Откат доступен на сохранённую меньшую версию, а обычный импорт понижения версии отклоняется.

В `updates-v1/last-install.json` профиля сохраняются только стадия, числовой код и время, без музыкальных данных. Код 5 — контрольная сумма, 7 — ошибка помощника. Результат ошибки отображается в настройках при следующем запуске. Старый установщик можно запустить вручную, если приложение вообще не открывается. Автоматического отката по аварии нет.

С 1.0.9 публичный источник — `https://api.github.com/repos/arthurhoodwin/wave/releases/latest`. Проверка запускается явно в настройках, без авторизации VK. Загрузчик принимает только HTTPS GitHub и его asset-CDN, выбирает `Wave-VERSION.waveupdate`, ограничивает размер/время, удаляет временный пакет при ошибке и передаёт его существующему проверяющему модулю. Подписанная версия должна совпасть с публикацией. Для установки остаётся отдельное подтверждение. Импорт файла сохранён. Ротация ключа требует переходной версии, доверяющей новому ключу.

NSIS-настройки сверены с [документацией electron-builder](https://www.electron.build/v26/docs/nsis/). Подпись Ed25519 пакетов Wave — собственный формат и не является подписью Authenticode Windows.

## Если новая версия не работает

1. Если Wave открывается, нажмите **«Восстановление»** после некорректного завершения либо **Настройки → Откатить на …**. Установится сохранённый подписанный/проверенный установщик; отдельное подтверждение обязательно.
2. Если Wave не открывается, завершите её и запустите сохранённый установщик из `%LOCALAPPDATA%\Wave\installers` или скачайте нужный выпуск из GitHub Releases. Не удаляйте профиль ради переустановки.
3. Перед ручными действиями можно скопировать `%APPDATA%\wave-vk-research-client` в локальную резервную папку. Это чувствительные данные сеанса VK: не отправляйте их в issues или третьим лицам.
4. Если приложение вообще не запускается и откат не помог, приложите версию и текст ошибки без cookies, токенов и аудиоссылок. Authenticode-сертификата у установщика пока нет.

`updates-v1/session-health.json` содержит только версию и признак чистого завершения. Некорректный выход той же версии даёт предложение восстановления, но не доказывает причину сбоя и не запускает откат сам. При выключении питания признак также может остаться незакрытым.

## Миграции настроек

1.0.9 добавляет `settingsVersion: 1`, `crossfadeSeconds: 0` и `preloadNext: true`. Параметры прежних версий проходят через тот же явный нормализатор и сохраняются. Некорректные типы заменяются безопасными значениями. Откат на старую версию не удаляет музыкальную коллекцию, но при сохранении настроек старый выпуск может отбросить неизвестные ему новые поля; при повторном обновлении для них будут использованы значения по умолчанию. Формат аудиокэша не меняется, поскольку скачивание аудио ещё не реализовано.

Проверки независимых Windows-компьютеров и новых аппаратных конфигураций нельзя заменить тестовым стендом на одном компьютере; они остаются отдельным этапом перед 1.1.
