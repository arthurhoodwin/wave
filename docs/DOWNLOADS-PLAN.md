# Скачивание и офлайн-библиотека Wave

Состояние: **1.1.0 Stable**, 25 октября 2026. Имя файла сохранено для существующих ссылок; основной текст теперь описывает реализованное поведение, а не обещание будущей Alpha. История — [CHANGELOG.md](CHANGELOG.md), доказательства — [VALIDATION.md](VALIDATION.md).

## Что работает

| Возможность | Текущее поведение |
| --- | --- |
| Запуск скачивания | Кнопка в строке или выделение в коллекции/плейлисте. В «Скачанном» выделения нет |
| Большой список | До 5000 выбранных записей в пределах ёмкости каталога, без обрезания до 100 |
| Подача задач | До 100 queued/running, остальные waiting; worker скачивает последовательно |
| Полный журнал | Отдельный зашифрованный `<hash>.queue.dat` по аккаунту; принимается только после сохранения |
| Перезапуск | Восстановленные задачи на паузе, доступны «Продолжить все», «Пауза всех», «Отменить все» |
| Результат | Число добавленных/пропущенных; готовая копия — галочка. В длинной очереди отображаются первые 100 строк с явным общим количеством |
| Хранилище | Выбор папки/лимита; квота учитывает частичные файлы. Одна локальная запись может включать аудио, JSON и обложку |
| Локальное воспроизведение | Проверенные байты и Range-перемотка без удалённого источника; пропуск несохранённых песен без сети |
| Удаление копии | Удаляются сгенерированные локальные файлы, запись VK не удаляется |
| Аккаунты | Раздельный индекс/очередь; смена аккаунта ставит работу на паузу и отзывает старые локальные handles |

«Все загруженные песни» относится к доступному представлению с учётом фильтра. Частично полученный серверный плейлист нельзя считать полностью выбранным. Уже скачанные/стоящие в очереди записи не добавляются повторно; это защита загрузок, не отдельный пользовательский диалог проверки дубликатов.

## Форматы и восстановление

Прямые MP3/M4A/WAV/AAC и совместимые **завершённые** HLS: packed AAC/MP3, AAC в MPEG-TS, fMP4, обычный AES-128 identity. Из TS извлекается AAC PES, fMP4 сохраняет init/фрагменты. Результат не превращается в MP3 переименованием расширения. DRM/SAMPLE-AES, live, byte-range HLS, discontinuity и прочие явно неподдерживаемые варианты отклоняются.

Прямой файл продолжается с сохранённого места только при совпавших source, strong ETag и корректном Range-ответе. Смена ETag/источника, 416 и истёкшая ссылка не приводят к склейке разных файлов. Без подтверждения неизменности начинается полная загрузка. После паузы HLS собирается заново; оборванный сегмент повторяется целиком без дубля префикса.

GET-повторы ограничены и учитывают Retry-After; отклонённая временная ссылка разрешается заново однократно. Потолок одного файла — 512 МиБ, время операции — 10 минут. Недостаток места, квота и отказ записи журнала не выдаются за готовую локальную копию.

## Каталог и целостность

- Перед доступностью офлайн проверяются сигнатура формата, фактический объём, длительность через изолированный Chromium и SHA-256.
- Подписанные аудиоссылки/авторизация не сохраняются в музыкальном JSON. Метаданные нормализуются через trackData.
- Аудио/JSON/обложки лежат в выбранной папке **без шифрования**. Индекс и полный журнал — в профиле с safeStorage.
- Старый personal-index остаётся schema 1; новый журнал мигрирует прежнее поле queue. Старые версии его не обрезают, но не умеют им управлять. Их уборка частичных файлов может потребовать повторной загрузки после возврата в новую версию.
- Нечитаемый/неизвестный журнал не заменяется пустым. Готовая песня остаётся в каталоге только после успешного сохранения записи.
- Встроенные ID3/MP4-теги и дополнение обложек старых копий **не реализованы**; новые записи сохраняют отдельный JSON и доступную обложку. Это перспективные улучшения, не скрытые условия Stable.

## Исторические ориентиры исследования

Предварительно изучены описания самих проектов; работа расширений и актуальность на реальном аккаунте пока не проверены. Это кандидаты для дальнейшего чтения кода, не готовая зависимость Wave.

| Проект | Что исследовать |
|---|---|
| [GeoXTen/vk-downloader](https://github.com/GeoXTen/vk-downloader) | Авторы описывают сохранение аудио с демультиплексированием HLS через hls.js; проверить фактические контейнеры/кодеки и лицензию |
| [Kos-Ko-ru/vk_media_saver](https://github.com/Kos-Ko-ru/vk_media_saver) | Обнаружение потоков и последовательную загрузку HLS-сегментов. Управление DOM VK не требуется переносить: у Wave уже есть сетевой адаптер |
| [IgorFZ/media-saver](https://github.com/IgorFZ/media-saver) | Локальную сборку потоков и извлечение аудио через FFmpeg WebAssembly; сравнить с подходящим для Electron решением по размеру, памяти и лицензии |

Код не переносится до проверки лицензии и совместимости с GPL-3.0-only. Расширения не устанавливаются и не получают доступ к пользовательскому профилю в рамках этой подготовки.


Ориентиры выше описывают прежний этап исследования, не установленные зависимости. Код расширений в Wave не переносился; обычная работа приложения их не требует.
