# Скачивание и офлайн-библиотека — план 1.1

Статус: прямые MP3/M4A/WAV и локальный каталог реализованы в **1.1.0-alpha.1**. Хранение по аккаунтам, потоковая запись, размер/SHA-256/Chromium-проверка, офлайн-Range, выбор папки и лимита, пауза с началом заново и отмена. Код расширений не заимствован: используется собственный VK-адаптер. HLS, продолжение по Range, очередь после перезапуска, автономные обложки и теги файлов остаются на Beta. Локальная музыка — отдельный слой данных, а не кэш метаданных.

## Пользовательский сценарий

- Скачать отдельную песню, несколько выбранных песен или плейлист. Показать прогресс, отмену, паузу и результат каждой операции.
- Раздел «Скачанное» и отметка доступности офлайн в обычных списках.
- Выбор папки и лимита места, просмотр занятого объёма, удаление локальной копии без удаления записи из VK.
- Названия файлов, исполнители, обложки и корректные теги; не обещать качество выше исходного.
- При отсутствии сети играть проверенную локальную копию. Удалённый или повреждённый файл имеет понятное состояние и повторную загрузку при доступном источнике.

Предварительно изучены описания самих проектов; работа расширений и актуальность на реальном аккаунте пока не проверены. Это кандидаты для дальнейшего чтения кода, не готовая зависимость Wave.

Код не переносится до проверки лицензии и совместимости с GPL-3.0-only. Расширения не устанавливаются и не получают доступ к пользовательскому профилю в рамках этой подготовки.

## Предлагаемое устройство Wave

1. **Свежий источник.** Получать временную ссылку через существующий VK-адаптер, сохранять музыкальный идентификатор и параметры файла, а не подписанную ссылку в постоянном каталоге.
2. **Прямое аудио.** Для MP3/другого готового файла — потоковая запись во временный файл. Возобновление по Range только при поддержке сервера и проверке неизменности содержимого.
3. **HLS.** Разобрать плейлист, загрузить init/сегменты в правильном порядке и собрать корректный контейнер. MP3, AAC и fMP4 — разные случаи: переименование расширения не является конвертацией. DRM и ограничения доступа не обходятся.
4. **Менеджер задач.** Ограничение параллельности, приоритет воспроизведения, отмена, пауза, повтор после сетевого сбоя и обновление истёкшей ссылки. Не блокировать интерфейс сборкой файла.
5. **Проверка результата.** Проверить полноту, декодирование и метаданные; только затем атомарно пометить файл готовым. Незавершённый файл не отображается как доступная офлайн-песня.
6. **Каталог локальных копий.** Хранить соответствие точной записи файлу, размер, формат, состояние и контрольную сумму. Не смешивать разные версии песни по одному названию. Изолировать индексы аккаунтов и явно определить поведение при выходе/смене аккаунта без случайного удаления пользовательских файлов.
7. **Локальное воспроизведение.** Подключить файлы к существующему плееру, эквалайзеру, перемотке и контексту списка через ограниченные команды, без произвольного чтения файлов renderer-процессом.

## Критерии готовности

Проверены прямое аудио и поддерживаемые HLS-варианты, обрыв/продолжение, истёкшая ссылка, нехватка места, дубликаты, повреждённый/вручную удалённый файл, перезапуск и смена аккаунта. Скачанный плейлист воспроизводится без сети; удаление локальной копии не меняет VK. Файл не объявляется MP3, если фактический кодек/контейнер другой.

Скачивание применяется к записям, которые пользователь вправе сохранять, без обхода DRM и ограничений доступа. Конкретные технические и сервисные ограничения фиксируются после исследования, а не скрываются за обещанием «скачать всё».
