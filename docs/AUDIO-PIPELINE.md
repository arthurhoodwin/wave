# Аудиотракт и EQ

Актуально для1.2.0-beta.2,28октября2026.

## Подключение

equalizer.js создаёт общий window.waveAudio до загрузки media-player.js. AudioContext откладывается до attach. Плеер создаёт HTMLAudioElement сanonymous CORS и подключает MediaElementSource → crossfade envelope → десять peaking BiquadFilter → output gain → destination. Текущая/подготовленная/затухающая песни используют один EQ, собственного эквалайзера для второго источника нет. При удалении источника disconnect разрывает source/envelope; engine.info отражает число соединений. MP3/HLS используют одну цепочку.

В Beta1 выбор пресета/движение полосы сохраняли enabled=false, поэтому изменение могло происходить без обработки. Полосы были неравномерно расположены, а пресеты расширялись из6 значений; автоматический запас составлял измеренный пик+3дБ. Сам DSP при включении работал: прежняя проверка тонами дала bassTilt7,91дБ/vocalTilt6,77дБ, но общий уровень заметно снижался. Поэтому жалоба не трактуется как отсутствие Biquad-обработки вообще.

## Beta2

Центры31,5/63/125/250/500/1000/2000/4000/8000/16000Гц, Q1,4, каждая полоса−12…+12дБ шаг0,25. Пресеты заданы непосредственно десятью значениями. Выбор пресета/ползунка включает EQ, explicit switch позволяет bypass. При bypass gain всех фильтров0 и выходной gain1.

Headroom рассчитывается по суммарной АЧХ через реальные getFrequencyResponse; резерв после пика1дБ вместо3. Математическая RBJ-модель используется для SVG-кривой и fallback, не сумма всех положительных полос. info возвращает сохранённую компенсацию, не пересчитывает2048точек на каждом чтении. Сглаживание полос15ms, восстановление выходного gain50ms. Это не loudness-нормализация, не компрессор и не обещание одинаковой воспринимаемой громкости пресетов.

## Совместимость

Новая настройка хранится вwave-equalizer-v2. При отсутствии v2 читается v1;6 или10 прежних полос интерполируются по логарифмической шкале на новую сетку, значения ограничиваются безопасным диапазоном. v1 не удаляется. Существующая пользовательская кривая может отображаться как «Свой», поскольку новые пресеты имеют другие значения.

Новые бас/вокал дают относительные наклоны9,2633/9,5060дБ; отдельная полоса1000Гц+12дБ даёт11,9672дБ относительно63Гц. Bypass совпал с flat с допуском1e−5. Это проверка реальной WebAudio-обработки, не субъективное прослушивание и не характеристика колонок пользователя.

Кривая SVG статична между изменениями, десять ползунков в одном ряду с внутренней прокруткой на узком окне. UI использует текущие theme tokens и existing modal/dropdown. Экспорт диагностик не включает названия треков, ссылки и аккаунт.
