# Сторонние компоненты

Лицензия Wave не заменяет лицензии перечисленных компонентов. Полные сведения о закреплённых версиях — в package-lock.json.

| Компонент | Лицензия | Где находится / источник |
|---|---|---|
| Hls.js 1.7.3 | BSD-2-Clause | `src/renderer/vendor/hls.LICENSE`; https://github.com/video-dev/hls.js |
| Inter Variable | SIL Open Font License 1.1 | `src/renderer/fonts/Inter-LICENSE.txt`; https://github.com/rsms/inter |
| Electron | MIT и лицензии Chromium/Node.js | Поставляемые Electron `LICENSE` и `LICENSES.chromium.html`; https://github.com/electron/electron |
| electron-builder | MIT | Инструмент сборки; https://github.com/electron-userland/electron-builder |
| sharp | Apache-2.0 и лицензии его зависимостей | Инструмент подготовки иконки; https://github.com/lovell/sharp |

Иллюстрации и демонстрационные данные для README подготовлены для Wave. Названия демонстрационных песен не обозначают каталог VK. Текст в снимке развёрнутого плеера — специально написанный пример.

Музыка, обложки реальных релизов, тексты и другие данные VK принадлежат их правообладателям. Репозиторий их не распространяет. Товарные знаки упоминаются для указания совместимости.
