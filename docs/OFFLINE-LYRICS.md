# Тексты скачанных песен · 1.2.2

Текст открывается обычной кнопкой песни. Если аудио скачано, положительный результат сохраняется рядом с ним; уже найденный результат из LyricsSources копируется после завершения скачивания. Никакого фонового поиска по старой коллекции нет. Сохранение не задерживает ready аудио, ошибка текста не превращает готовую песню в ошибку загрузки.

## Файлы и индекс

`<download UUID>.lyrics.json` содержит schema1, SHA-256 идентификатора аккаунта, VK-ключ исходной локальной записи, дату, нормализованные text/timings/syncedLyrics/source/credits/url. Текст и метки хранятся без TTL. Файл — обычный JSON без шифрования, как аудио/обложки; credentials и произвольные поля не копируются. Внешние ссылки ограничены существующим allowlist источников и открываются прежним проверяемым способом.

Лимит файла2МиБ; размер и SHA-256 находятся в необязательном record.lyrics. Основной personal-index остаётся schema1; storageBytes аудио/обложки/метаданных не меняет смысла. Квота и usedBytes дополнительно учитывают lyrics.bytes. Бронирование использует общий budgetTail/reservations загрузчика и не забирает уже зарезервированное аудио место. Повторное сохранение одинакового текста не переписывает файл.

Запись через уникальный temp с wx, затем rename. При чтении и перед фиксацией проверяются аккаунт, существование локальной записи и путь папки; symlink вместо sidecar не читается. При ошибке сохранения индекса восстанавливается прежнее содержимое/дескриптор. Текст всё равно можно прочитать онлайн, но интерфейс сообщает, что офлайн-сохранение не удалось. Отсутствие/повреждение файла не блокирует песню.

## Получение и обновление

Сначала читается постоянный sidecar, затем обычный кэш/сеть. «Обновить текст» принудительно обходит оба кэша, обновляет постоянную копию только положительным результатом. Пустой результат или ошибка оставляет прежнюю копию. Без сети кнопка недоступна; при отсутствии текста — объяснение без retry-loop. Обычные песни без локальной копии по-прежнему используют ограниченный TTL-кэш.

downloadAliases связывают новый VK-ключ лайка с исходной локальной записью; для имени файла не используется присланный renderer путь. При удалении записи сначала сохраняется обновлённый индекс, затем последовательная очередь sidecar удаляет текст: ожидающее сохранение не может воскресить удалённую копию. Тексты другого аккаунта не отображаются.

## Совместимость

Старые1.2.x игнорируют record.lyrics. Если при откате старый клиент пересохранил индекс без этого поля, новая версия распознаёт оставшийся sidecar по UUID/аккаунту/ключу, нормализует содержимое и восстанавливает дескриптор. Если старый клиент удалил аудио, оставшийся текст самостоятельно не становится песней и не импортируется. Удаление sidecar вместе с аудио поддерживается начиная с1.2.2; пользователю не обещается новая логика удаления внутри старого приложения.

Модули: src/main/lyrics/offline-lyrics.cjs, lyrics-service.cjs; интеграция main.cjs/provider.cjs/download-manager.cjs/personal-library.cjs; интерфейс song-view.js. Проверки — tests/offline-lyrics.test.cjs и native discovery UI. Реальная доступность текстов у внешних источников зависит от сети и самих источников.
