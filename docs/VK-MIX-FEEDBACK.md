## Подготовленная реализация

- Два точных write-метода в allowlist; нет произвольного метода или удаления из коллекции. readDislike делает свежий audio.getById, проверяет точную owner/id identity и принимает boolean/0/1 либо отсутствие поля как false по подтверждённому контракту. Неизвестный тип и отсутствие самой записи — ошибка до записи.
- MixFeedback читает состояние до и после записи. Один pending на key, проверка account/epoch до применения, ограниченные receipts для Undo после смены текущего потока. Неизвестный track не принимается. Приватные ссылки и credentials в ответ renderer не входят.
- Неоднозначная запись блокирует повторную запись до отдельного Check; Check только читает. Успех не изображается оптимистической анимацией.
- Кнопка в нижнем и развёрнутом плеере видна только при активном Миксе. Подтверждённый отказ переключает песню, toast предлагает Undo; проверка неопределённого результата не переключает песню сама по себе. Лайки остаются отдельной функцией. В мини-плеере новая кнопка пока не добавлена.
- Возвращение сети повторяет ожидавшую загрузку только при том же generation/current/context. Пауза/перемотка/смена песни отменяют намерение автоматического продолжения.
- Неверный seed/options не завершает работающий поток; auth прекращает старую дозагрузку. До60 треков и1000 ключей сохранено.

## Реальная проверка и уточнение схемы

Владелец разрешил временно поставить признак одной песне и снять его. Первая проверка остановилась до записи: getById не содержал dislike. Затем обнаружено подтверждение SDK: getAudioExtra(...).dislike??false и source.audio.dislike??false. Контрактный тест на одной записи с явным исходнымfalse из потока дал: до записи getById без поля; audio.addDislike acknowledged=true; после записи getById.dislike=true; audio.removeDislike acknowledged=true; после снятия поле опять отсутствует. Это подтверждает omitted=false для найденной записи. Коллекция/лайки не изменялись, Wave возвращён. Дополнительный поиск не нашёл точный audio-ID и не использован как подтверждение. Отчёты вне Git: work/probe120b1-feedback.json (без записи), probe120b1-contract.json (один add/remove). Приватные IDs/URL/ключи в отчёте не сохранены.

Исходный признак снят; влияние кратковременного сигнала на алгоритм не объявляется отменённым. Основные функции прошли изолированные проверки, длительный реальный playback не выполнялся.
