# Wave — дизайн-код

Актуальная версия: **1.1.4 Stable**, 26 октября 2026. Это действующие правила интерфейса. Исторические варианты и причины перехода к текущему виду — в [DESIGN-AUDIT.md](DESIGN-AUDIT.md) и [CHANGELOG.md](CHANGELOG.md).

## Характер интерфейса

Графитовая основа, светлый основной текст, нейтральные серые подписи. Мятный — фирменный акцент для осмысленных действий и состояний. Не возвращать зелёные фоны на все поверхности и не перекрашивать реальные обложки. Не добавлять слоганы, повторный контекст и необязательные декоративные плашки.

## Где нужен мятный

- Логотип, основное цветное действие, заполненное сердце лайка.
- Небольшой маркер текущей песни и активных режимов, позиция песни.
- Клавиатурный фокус.

Скачанная копия — спокойная светлая галочка. Громкость и размер текста — нейтральные шкалы. Навигация — нейтральная подложка, без сплошного яркого выделения. Активная строка текста — светлый текст, вес и тонкая мятная линия; большой зелёной заливки нет. Ошибка не получает оформление успешного состояния.

## Типографика и геометрия

- Локальный Inter Variable с кириллицей/латиницей; fallback Segoe UI/sans-serif. Рабочий шрифт задаётся в refinements.css, файлы — в fonts.css. Старые промежуточные font-family в каскаде не являются новым дизайн-решением.
- Роли: подпись `.75rem` (12 px), малый текст `.8125rem` (13 px), основной `.875rem` (14 px), секция `1rem` (16 px). Базовый rem — 16 px.
- Обычный текст с unitless line-height около 1.5, заголовок 1.2–1.3; меняющиеся числа — tabular-nums. Не менять шрифт ради локальной правки.
- Радиусы: 6/10/16 px; основной шаг 8 px, промежуточные отступы кратны 4 px. Размеры сверять с существующим компонентом.
- Длинные названия должны иметь доступный полный вариант: title, раскрытие при фокусе или сведения о песне. Исполнители остаются отдельными ссылками.

| --- | --- |

| Настройки/восстановление | Открываются через профиль. Самостоятельных видимых кнопок настроек и восстановления в шапке нет |

| Медиатека | Закрепления, локальные папки, обычный/компактный вид. Отдельную «Главную», поиск и выбор порядка плейлистов не возвращать |
| Главная | Закрепления и доступные подборки VK. История и недавно открытые списки не дублируются |
| Системные шапки | Компактная однотонная поверхность, без overline, большой декоративной эмблемы и повторного счётчика |
| Скачанное | Обычный список с поиском/сортировкой. Без выделения, чекбоксов и массовой панели |
| Нижний плеер | Песня слева, транспорт в средней области, эквалайзер/мини-плеер и громкость справа. Мини-плеер расположен перед громкостью |
| Развёрнутый плеер | Обложка и метаданные слева, текст справа. Статус слева в футере, транспорт по центру, громкость справа |
| Настройки | Три нативных details: «Воспроизведение», «Библиотека и скачивание», «Приложение». Аккаунт видим сверху, версия — последней |

Native-окно рассчитано минимум на 1100×720. 320 px — дополнительный стресс-тест renderer, не обещание мобильного приложения. При ширине до 850 px правая группа нижнего плеера получает отдельную строку и не теряет мини-плеер/громкость при масштабе 200%. На узкой ширине медиатека доступна через диалог.

Обычный клик запускает песню сразу. Обязательной панели «Следующие песни» и кнопки «Загрузить ещё» нет. Боковые кнопки мыши выполняют назад/вперёд; назад закрывает просмотр песни перед сменой маршрута.

## Строки, действия и состояния

- Один набор SVG в icons.js: сетка 24 px, currentColor. Не использовать emoji вместо управляющих значков.
- В таблице отдельные колонки времени, лайка, скачивания и меню. Сетка заголовков и строк совпадает, значки центрируются без индивидуального смещения margin.
- Обычный, hover, selected, current, busy, disabled и error различаются. Лайк использует заполненное сердце, скачивание — галочку; значение не кодируется только цветом.
- Pending локален выбранной операции; не блокировать весь список из-за одного лайка. Для значков — aria-label, для переключателей — aria-pressed, для операции — aria-busy.
- Меню песни — компактный native popover. Удаление/потеря локальной копии подтверждаются. Диалог не заменяет быстрые сердце/скачивание в строке.
- В больших списках переиспользовать DOM и виртуализацию. Прогресс песни не должен пересоздавать медиатеку.
- «Все загруженные песни» обозначает частичный список; не выдавать его за полный серверный плейлист. В «Скачанном» модификаторы Ctrl/Shift не включают выделение.

## Движение и доступность

| Сценарий | Правило реализации |
| --- | --- |
| Открытие диалога | motion.js: opacity + translateY(12px), 300 ms |
| Закрытие | opacity + translateY(-12px), 150 ms |
| Easing диалогов | cubic-bezier(0.2,0,0,1); новое действие отменяет предыдущее завершение |
| Reduced motion | Диалоги — только opacity 100 ms; сдвиги/масштабы отключаются |
| Частые взаимодействия | Мгновенно либо короткий переход фона/прозрачности, без каскадов строк |
| Нажатие основной кнопки | Scale .96 / 150 ms / ease-out только для доступной кнопки и no-preference |
| Смена активной строки | По временной метке воспроизведения, не по окончанию анимации; не добавлять задержку тайминга |

Native dialog/showModal, Escape, удержание/возврат фокуса; native details раскрывается Enter/Space. Focus-visible — 2 px с offset 3 px; в forced colors применяются системные цвета. Текст должен проходить 4.5:1, крупный текст и значимые управляющие значки — 3:1. Не снижать контраст через opacity ради декоративного приглушения.

## План развития движения после 1.1.0

Действующее поведение выше не следует путать с намеченными улучшениями. [MOTION-AUDIT.md](MOTION-AUDIT.md) фиксирует срез исходников, статичную волну текущего трека, мгновенные icon swaps и план последовательной полировки; [ROADMAP.md](ROADMAP.md) распределяет работу по 1.1.x–1.2. Новый motion-сценарий проектируется вместе с функцией, включая pause/error/disabled/reduced-motion и отмену. Живые полоски обозначают состояние воспроизведения, не измеренный спектр звука. До реализации и runtime-проверки эти эффекты не считаются частью Stable.

## Реализовано в 1.1.1

Индикатор текущей строки — четыре полоски с transform/разными фазами; на паузе они неподвижны, во время подключения заменены отдельным знаком. IntersectionObserver ограничивает движение видимыми строками; native show/hide/minimize/restore дополняют document.visibility, поскольку backgroundThrottling:false сохраняет работу Chromium. При reduced-motion цикл отключён. Иконка настройки эквалайзера этим не затрагивается.

Копирование ссылки подтверждается текстом «Ссылка скопирована» и однократным спокойным переходом фона доступной кнопки. Общая геометрия, focus и muted/active цветовые роли сохраняются. Прочие улучшения из MOTION-AUDIT ещё остаются планом.

В hotfix 1.1.1.1 непрерывная интерполяция полосок заменена steps(4,end): на контрольном стенде около 12 обновлений/с вместо 60. Лёгкие декоративные циклы проверять измерением частоты кадров/нагрузки до выпуска; небольшой размер значка не гарантирует низкую стоимость композитинга.

## Выделение и шапка в 1.1.2

Выбор: левый Shift+ЛКМ переключает отдельную песню, Ctrl+A выбирает весь уже загруженный отфильтрованный список. Нижняя выбранная песня определяется текущим порядком, не очередностью кликов. Только её троеточие доступно при выделении; остальные скрываются с сохранением геометрии столбца и исключаются из Tab. Меню содержит групповые действия и снятие выделения. Обычный клик воспроизводит и снимает выделение; Escape очищает его после закрытия popover. Ctrl+Space и Shift+F10 дают клавиатурный путь, редактируемый текст и открытые диалоги не перехватываются. Состояние выбора обозначено фоном/линией, именем группы строки и доступным счётчиком. В скачанном выбора нет.

Шапка: кнопки rename/link — SVG currentColor, область 40×40 px, title и aria-label. Подписи в tooltip — «Переименовать плейлист» / «Скопировать ссылку». Отдельных кнопок выбора и копирования плейлиста нет. Изменения не добавляют циклических анимаций.

## Страница исполнителя

Отдельные баннер и аватар; широкое generic-фото не кадрируется автоматически в круг. Шапка без подходящего изображения сохраняет нейтральный градиент. Навигация под шапкой — текстовые вкладки с тонкой мятной линией, не поисковые pills; без счётчиков. Горизонтальная прокрутка названий вместо их обрезки. Карточки сохраняют квадратные обложки и виртуализируются; повторные данные не запускают каскад анимаций. При неполной классификации используется общая вкладка «Релизы».

Если одна из категорий альбомы/синглы пуста или есть неизвестный тип, вместо двух вкладок используется одна «Релизы». Отдельной секции «Релизы без указанного типа» нет. Вкладка треков называется «Популярные треки» только при подтверждённом источнике популярности; иначе «Треки». Пустая таблица и неработающие инструменты не отображаются.

При чтении страницы артиста вкладки и содержимое разделов скрыты. Показывать финальную навигацию только после получения данных, чтобы пользователь не видел смену «Альбомы/Синглы» на «Релизы» или «Треки» на «Популярные треки». То же правило действует при refresh; сообщение загрузки остаётся видимым, лишняя анимация появления не добавляется.

## Главная1.1.4

Разделы плейлистов и песен имеют разные действия карточек: открыть список или начать выбранный контекст треков. Неподдержанные действия Микса не изображаются работающими плейлистами. При повторном чтении одинаковые секции/карточки сохраняют DOM и фокус; фоновые изменения не запускают появление всей страницы. Частичный сбой обозначается одним статусом с повтором, успешные карточки остаются доступны. Подтверждённые имена альбомов обновляются без перезапуска музыки; до уточнения placeholder показывается нейтральное «Открыть альбом».
