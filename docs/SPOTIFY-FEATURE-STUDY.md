# Spotify: повторное исследование для роадмапа Wave

23 октября 2026. Исследованы поставляемые ресурсы установленного Windows-клиента, а не исходники открытого проекта или список функций по памяти. Это **статическое исследование**, не проверка поведения авторизованного Spotify. Доступность функций зависит от сборки, флагов и аккаунта.

## Источник и метод

Источник — локальный `Spotify/Apps/xpui.spa`, SHA-256 `19be39b9f8da51a5e766699bc0e7a8bf6dc6f09b1b733a2d8feb4cb2e1ce0608`, 587 ZIP-записей. Подлинность/отсутствие пользовательских модификаций пакета не доказаны; надёжный номер версии не установлен. Это снимок конкретной установленной поставки, а не утверждение о всех версиях Spotify.

REA распознал архив. Полный inventory отклонён из-за небезопасной записи `/`; архив целиком не извлекался. Выбранные известные файлы скопированы побайтно в отдельный рабочий каталог, без запуска. REA проанализировал три JS-файла: настройки, плейлист и локальные файлы; 197 336 байт, 59 710 AST-узлов, 43 модуля, 0 ошибок разбора. Семантическое покрытие частичное: ограничение 2 000 узлов на файл / 6 000 всего, неразрешённые импорты. Наличие привязки настройки не доказывает реализацию native DSP.

## Что найдено

| Возможность | Статическое доказательство | Что можно независимо реализовать в Wave |
|---|---|---|
| Эквалайзер | `xpui-routes-desktop-settings.js`: вызов setFilterGain, частотные ползунки, пресеты и сброс; REA-анализ выбранного файла | Web Audio EQ, пресеты и bypass с защитой от перегруза. Поведение и частоты выбирать/проверять самостоятельно |
| Crossfade | Там же: параметры playback.audioCrossfade / audioCrossfadeMs, обработчик длительности; код UI содержит шкалу до 12 секунд | Собственная настройка перекрытия двух треков. Нужны два источника, предзагрузка и отмена при смене контекста |
| Gapless | Там же: чтение playback.gapless и mutate-переключатель | Проверить непрерывное воспроизведение на поддерживаемых форматах; не обещать нулевой разрыв до измерения |
| Нормализация | Там же: setNormalizeValue/setVolumeLevel и ветки подтверждения; локализация описывает одинаковую громкость | Исследовать отдельно: VK не гарантирует loudness-метаданные. Один компрессор не выдавать за нормализацию |
| Локальная музыка | Настройки: browseForFolder/addFolder и источники; `xpui-routes-collection-local-files.js`: отдельный экран/треклист, оба файла включены в REA | Локальные папки пользователя, индексация и воспроизведение собственных файлов без загрузки в VK |
| Папки плейлистов | Целевой поиск `xpui-routes-your-library-x.js`: folderUri и создание; ключи локализации папок/перетаскивания | Локальные папки Wave поверх VK-плейлистов, без обещания синхронизации такой структуры в VK |
| Дубликаты при добавлении | Только ресурсные ключи duplicate.tracks: уже добавлено, добавить новые, всё равно добавить | Собственная проверка точных записей перед пакетной записью; работающее поведение Spotify не наблюдалось |
| Полноэкранный текст | Только ключи lyrics.fullscreen / cinema-mode / unsynced | Самостоятельный полноэкранный режим; временные метки получать только из доступного VK-источника |
| Разделение результатов поиска | Ключи songs/artists/albums/playlists и экран поиска; в целевом JS-поиске непосредственно найдены tracks/all, остальные вкладки не прослежены полностью | Раздельные сущности вместо одних песен. Сначала подтвердить методы и данные VK для каждого раздела |

## Выбор для плана

1.0.4 — EQ; 1.0.5 — поиск по типам; 1.0.6 — папки плейлистов; 1.0.7 — работа с дубликатами и копирование плейлиста; 1.0.8 — полноэкранное Now Playing/текст; 1.0.9 — crossfade и проверенный gapless. Основные исправления стабильности, поиска, производительности и обновлений сохраняются в соответствующих версиях.

По решению владельца 1.1 сохраняет прежние цели: домашняя, постоянная история, организация медиатеки и необязательная панель следующих песен. Локальные файлы — кандидат для дальнейшего развития без назначенной версии. Нормализация остаётся исследованием, а не обещанием готового алгоритма. Spotify Connect, Blend, персональное радио и рекомендации нельзя получить одной оболочкой без соответствующих сервисов; в обязательный план они не включены.

## Граница независимой реализации

В Git публикуется только это текстовое описание. JS Spotify, архив, оригинальная графика и локализация не добавляются в Wave. Исходная реализация DSP, классы и внутренние сетевые вызовы не переносятся. После чтения поставляемого JS нельзя называть текущий процесс строгой чистой комнатой; этот документ — исследование продукта и функциональный ориентир, а будущий код Wave пишется самостоятельно. Наблюдение запущенного Spotify, конкретные размеры UI, DSP и переключение каждого флага остаются непроверенными.
