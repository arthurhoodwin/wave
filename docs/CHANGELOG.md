# Изменения

## 1.1.0-alpha.2 — 24 октября 2026

* История после 0,5 секунды фактического воспроизведения.
* Главная без повторов истории: закрепления и каркас рекомендаций, плейлистов дня и новых релизов.
* Открытые списки перенесены в «Недавно прослушанное»; верхняя кнопка воспроизведения и счётчики убраны.

* Повтор всего списка ждёт завершения его загрузки и не зацикливается при ошибке. «Предыдущий» остаётся в текущем списке.
* Обновление кэша обновляет доступность уже известных песен; недоступные пропускаются.
* Неизменившиеся списки не пересоздают DOM. Метаданные обновляются без срыва текущего воспроизведения.
* Версия отображается в интерфейсе; добавлены автоматические проверки критичных сценариев.
