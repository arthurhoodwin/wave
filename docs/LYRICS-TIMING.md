## Наблюдение VK

В авторизованной Wave исследована структура HTTP-ответа `audio.getLyrics`. Обёртка HTTP содержит `response`, внутри — `md5`, `lyrics`, `credits`. В проверенном ответе `lyrics` содержит `language` и массив `timestamps`. Элемент массива: `begin: number`, `end: number`, `line: string`. Значения времени заданы в миллисекундах: 10 928 → 10,928 секунды, что согласуется с длительностью 90 секунд. Содержимое `line`, данные авторизации и аудиоссылки не записывались в отчёт.

Адаптер поддерживает этот вариант и прежние варианты `lyrics.text: string[]` / `text: string`. Неверные метки не превращаются в выдуманную синхронизацию: доступный текст можно показать статически. Код — `src/main/lyrics/vk-lyrics.cjs`.

## LRCLIB

[Документация LRCLIB](https://lrclib.net/docs) описывает plainLyrics и syncedLyrics. Проверен ответ для Radiohead / Creep с длительностью 238 секунд: поле syncedLyrics содержало 38 строк с метками вида `[00:19.16]`. Текст в репозиторий не переносился. Реализован собственный ограниченный парсер LRC: дробные секунды, повторные метки, объединение одинаковых моментов, offset. Семантика положительного offset как сдвига раньше сверена с [описанием paroles](https://github.com/Clarkkkk/paroles); код этой библиотеки не используется. Пословные тайминги не реализованы.

## Идентичность и жизненный цикл

VK запрашивается по частной идентичности конкретной аудиозаписи. Для внешнего источника сохраняются проверки названия, всех исполнителей и доступной длительности. Подсветка разрешена только при полученных числовых метках, а не рассчитанном из длины текста времени.

Клиент использует точную позицию аудио из событий плеера. Пользовательская прокрутка останавливает автослежение до явного возврата. Поздний ответ проверяется по номеру запроса и идентификатору песни. Кэши ограничены количеством, бюджетом содержимого и временем; очищаются при выходе и смене аккаунта.

Проверены клавиатура, axe и дерево доступности Chromium. Ручная проверка экранным диктором и переключение системного DPI на других Windows-компьютерах остаются отдельными задачами. Работа Genius всё ещё зависит от доступности сайта; подтверждённые метки сейчас получены от VK и LRCLIB.
