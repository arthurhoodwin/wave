# Безопасность

Проект пока не прошёл независимый аудит безопасности. Для исправлений поддерживается последняя версия.

Для приватного сообщения используйте **Security → Advisories → Report a vulnerability**, если эта возможность включена в репозитории. Не раскрывайте секреты в публичных issues. Если приватная форма недоступна, откройте issue только с просьбой предоставить закрытый канал, без деталей уязвимости.

В сообщении достаточно версии, описания проблемы и воспроизведения с искусственными данными. Не отправляйте действующие токены, cookies, профиль Electron, закрытый ключ обновлений и полные ссылки аудиопотоков. Скриншоты предварительно обезличьте.

Не заявляем SLA исправления. Обычные ошибки интерфейса и воспроизведения оформляйте через шаблон bug report.
