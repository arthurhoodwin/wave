# Wave 0.8.0 — Авторизация и установка

## Возможности

* Установщик Windows x64 с выбором каталога, ярлыками и собственной иконкой. Администратор для установки в профиль пользователя не требуется.
* Настройки «⚙»: выход из VK и смена аккаунта. Выход останавливает плеер, отменяет запросы и попытку входа, удаляет локальные cookies/хранилища VK и зашифрованную музыкальную коллекцию. Сеансы системного браузера не затрагиваются.
* Маркер выхода не позволяет автоматически восстановить прежний сеанс после перезапуска даже при прерванной очистке. При ошибке очистки смена аккаунта блокируется до повторного выхода.
* Вход в официальном окне VK; закрытие окна отменяет ожидание, успешный вход скрывает окно.
* Обновления из `.waveupdate`: встроенный публичный ключ Ed25519 проверяет подпись манифеста, продукт, архитектуру, версию, размер и SHA-512 установщика. Неизвестный издатель, повреждённый файл и обычное понижение версии отклоняются.
* Предыдущие установщики сохраняются для ручного отката в настройках. Перед запуском установщик проверяется повторно; запись истории защищена Electron safeStorage. При обновлении и откате сохраняются вход и коллекция.

## Использование

Запустите `../wave-releases/Wave-Setup-0.8.0.exe`. Прежний вход Wave подхватится автоматически. Настройки открываются кнопкой «⚙» рядом с поиском. Для будущего обновления выберите полученный файл `.waveupdate`, затем «Установить». После установки следующей версии станет доступен откат на сохранённую предыдущую.

По согласованию с пользователем системный браузер пока не используется: своего зарегистрированного VK ID-приложения нет. Скачивание обновлений с сервера не включено — адрес публикации не задан. Уже реализованы проверка и установка полученного файла; случайные URL и неподписанные EXE интерфейс не принимает.

Установщик пока не подписан сертификатом Authenticode: Windows может показать предупреждение о неизвестном издателе. Подпись пакетов Wave Ed25519 служит для проверки обновлений внутри приложения и не заменяет сертификат Windows.

Автоматического отката при аварии нет: откат выбирается пользователем в настройках. Старые версии используют совместимый кэш метаданных v1. Явный выход удаляет этот кэш; обычное удаление приложения сохраняет профиль.

## Проверки

`npm test`: **67 проверок, 67 успешных**. Включены прежние регрессии 0.7, очистка аккаунта, отмена входа, запоздалый токен после выхода, ошибка очистки, подпись обновления, подмена установщика, неверный издатель/продукт и запрет обычного понижения версии.

Реальные прогоны на текущем Windows-компьютере:

| Проверка | Результат |
|---|---|
| Установка в отдельную тестовую папку | NSIS exit 0, рабочая Wave.exe |
| Установка в `%LOCALAPPDATA%\Programs\Wave` | Exit 0, версия 0.8.0.0 |
| Ярлыки рабочего стола и меню «Пуск» | Оба указывают на финальную установленную Wave.exe |
| Вход после установки | Существующий сеанс сохранился, повторный ввод не потребовался |
| Собственный плеер | Реальная музыка, запуск около 0,26–0,29 с, пауза без ошибки |
| Настройки в установленной сборке | Выход, смена аккаунта и выбор обновления доступны |
| Подписанный тестовый пакет | Менеджер → помощник → NSIS → 0.8.1 → автоматический запуск |
| Откат | Тот же путь → сохранённая 0.8.0 → автоматический запуск, exit 0 |
| Очистка аккаунта в Electron | На отдельном синтетическом сеансе: cookies, зашифрованный файл и приватные идентификаторы очищены |
| Содержимое ASAR | Совпадает с исходниками, приватного ключа и тестовых файлов нет; помощник доступен вне ASAR |

Версия 0.8.1 служила только тестовой следующей сборкой. Её установщики и история убраны из рабочего профиля, финально установлена 0.8.0. Пользовательский VK-сеанс при проверках выхода не удалялся. Полный переход в другой реальный аккаунт не проверялся; логические сценарии покрыты тестами. Состав живой коллекции менялся пользователем в течение работы и не восстанавливался к старому числу.

В цикле установки исправлены особенности запуска PowerShell в фоновом процессе, UTF-8 пути с кириллицей, доступ к помощнику за пределами ASAR и отсутствие `Get-FileHash` в унаследованном окружении: используется потоковый SHA-512 .NET. Ошибка установки сохраняется числовым кодом и показывается в настройках после следующего запуска.

Замеры относятся к данному компьютеру и соединению. Сетевой адаптер и собственный плеер 0.7 сохранены. Проверка на других компьютерах, сертификат Windows, автоматическая публикация и автоматический аварийный откат остаются отдельными задачами.
