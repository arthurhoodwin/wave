# Wave 0.7.0 — Независимый VK-адаптер

23 октября 2026, Windows, Electron 45.0.0.

## Изменения

Обычный режим переведён на прямые запросы VK. Временный веб-токен получается из выделенного сеанса Wave. Личная музыка, полный список плейлистов, альбомы, поиск, исполнители и изменение коллекции работают по сети. Воспроизведение использует собственный HTMLAudio/Hls.js-плеер и ограниченный loopback-прокси.

Музыкальная страница VK в обычном режиме не загружается. Сохранены существующий вход, зашифрованный кэш, навигация и контекст воспроизведения. Официальное окно остаётся для входа, прежний адаптер — в исследовательском режиме.

Обновление токена однократное при подтверждённом отказе авторизации; параллельные запросы используют одну попытку обновления. При сетевой ошибке доступен кэш; переподключение начинается через 3 секунды с увеличением интервала до 30 секунд. Неоднозначные изменения коллекции не повторяются автоматически. Старый ответ другого аккаунта отклоняется.

Истёкшая потоковая ссылка обновляется однократно с сохранением позиции, громкости и намерения паузы. Новый выбор отменяет старое ожидание. Передача нового потока аннулирует старые прокси-адреса и запросы. Токен и исходный URL потока остаются в main; аудио не записывается на диск.

| Запуск песни | Около 0,25 секунды в измеренном прогоне |
| Создание тестового плейлиста | 267 мс, включая подтверждение VK |
| Переименование | 334 мс |
| Добавление песни | 356 мс |
| Песня в новом плейлисте | Успешное воспроизведение |
| Перестановка/удаление | Подтверждены чтением VK; текущая песня продолжила играть |
| «Мне нравится» | 369 → 370 → 369, обе операции подтверждены |
| Плеер | Пауза/продолжение, перемотка на 30 секунд, громкость, повтор одного, автопереход |

Это отдельные замеры данного компьютера и соединения, а не гарантия задержки. Тестовый плейлист удалён; пользовательский плейлист сохранён, исходные 369 песен и 15 плейлистов остались на месте.

## Автоматические проверки

`npm test`: **60 проверок, 60 успешных**.

Сценарии: первая страница и полный список из 1205 записей без браузера; точный счётчик и обрыв пагинации; старый поиск не заменяет новый; refresh после ошибки 5; защита от смены аккаунта; отсутствие повтора неподтверждённой записи; сохранение описания и приватности; переписывание HLS-сегментов и ключей в непрозрачные адреса; Range; аннулирование старой ссылки; однократное обновление потока с паузой и позицией; гонка выбора треков; прежние регрессии коллекции, интерфейса и зашифрованного кэша.

Естественное истечение многочасовой авторизации не ожидалось. Отказ и refresh проверены управляемыми ответами. Региональные ограничения и разные подписки не тестировались.
