# Wave 0.5.0 — удобная навигация

23 октября 2026. Запуск: `Start-Wave.cmd`.

## В выпуске

* Обложки в строках, боковой панели, карточках релизов, заголовке альбома и нижнем плеере. При отсутствии изображения остаётся значок.
* Клик по имени исполнителя открывает его каталог VK. Карточка релиза открывает страницу альбома со счётчиком и воспроизводимыми песнями.
* Назад/вперёд, Alt+← / Alt+→. Восстанавливаются прокрутка, число раскрытых строк, фильтр и сортировка.
* Поиск внутри текущего списка по названию и исполнителю, без нового сетевого запроса. Режимы сортировки: порядок VK, название, исполнитель, длительность, обратный порядок.
* Контекст нового воспроизведения соответствует отфильтрованному и отсортированному списку. Последующие изменения отображения не вмешиваются в звучащий контекст.
* Параметры последних 100 списков сохраняются между запусками. История переходов хранится в текущем окне.
* Сохранение альбомов и новых метаданных в существующий зашифрованный кэш. Обновление не требует повторного входа.

## Ограничения

Новые страницы исполнителей требуют сети. Представлен загруженный каталог VK; полнота дискографии не гарантируется. Для исполнителя без прямой ссылки сначала используется поиск VK. Релизы открываются из его каталога; отдельной глобальной страницы всех альбомов нет.

Локальный поиск работает по полученной части списка и дополняет результаты при фоновой загрузке. Обложки загружаются с доменов изображений VK; их доступность без сети не гарантируется. Если VK не отдаёт изображение, показан значок.

Первичное получение новых списков и звук по-прежнему зависят от VK. Установщик и авторизация через браузер по умолчанию не входят в 0.5.
