# Wave 1.0.3 — воспроизведение с okcdn.ru

Исправлена ошибка «Недопустимый сервер аудио VK». Для всех девяти треков альбома madk1d «sexyswag» VK возвращает прямые MP3 на `vd*.okcdn.ru`. Эти серверы успешно отдавали аудио, но отсутствовали в разрешённом списке локального прокси Wave.

В список добавлен домен `okcdn.ru` и его поддомены. Сохраняются HTTPS, запрет пользовательских данных в адресе и нестандартных портов, проверка границы домена. Варианты `okcdn.ru.evil.test` и `evil-okcdn.ru` отклоняются. В интерфейс передаются прежние непрозрачные локальные ссылки, приватные адреса потока не раскрываются.

## Проверка

- `npm test`: 95/95. Новый тест проверяет передачу Range/206, тип audio/mpeg, Content-Range, непрозрачность ссылки и отклонение похожих сторонних доменов.
- В действующем авторизованном сеансе проверены все девять треков альбома: серверы вернули 206/audio/mpeg.
- Все девять треков последовательно запущены в Wave: подтверждены playing=true и рост позиции, без прежней ошибки. Измеренный запуск вместе с 350 ms наблюдения: 0,51–1,10 секунды на этом соединении.
- Полное прослушивание каждой записи до конца не проводилось.

Вход, коллекция, оформление и функции 1.0.2 сохраняются. Установщик не подписан Authenticode; пакет `.waveupdate` использует существующую подпись Ed25519.
